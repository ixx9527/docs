# 数独解题技巧的快速识别

上一篇[《数独高级技巧的底层原理》](./sudoku-advanced-techniques.md)从逻辑学和组合数学的角度剖析了各种高级技巧为何有效。但实战中，更大的挑战往往不是"理解原理"，而是**快速识别**——面对一个复杂的局面，如何判断此刻该用哪种技巧？

本文的目标是建立一套**系统化的识别流程**，让你在解题时能高效地定位到正确的技巧，而不是盲目尝试。

---

## 一、识别的基本原则

在深入具体技巧之前，有几个贯穿全局的原则需要先明确。

### 1.1 从简到繁，逐层扫描

数独技巧的复杂度跨度很大——从一眼可见的唯一候选数，到需要追踪长链的 AIC。实战中应当遵循**成本递增**的扫描顺序：

1. 先检查零成本的局部约束（唯一候选数、隐性唯一数）。
2. 再扫描低成本的简单模式（裸对、隐对、区块排除）。
3. 然后寻找中等成本的结构模式（X-Wing、XY-Wing 等）。
4. 最后才考虑高成本的通用推理（AIC、试错法）。

这个顺序的核心逻辑是：**如果低成本技巧能取得进展，就无需付出高成本的认知负担**。

### 1.2 以数字为线索，而非以格为线索

多数中级技巧的识别都以**某个特定数字**为出发点。例如 X-Wing 的识别方式是："数字 5 在各行的分布情况如何？"而非"这个格有哪些候选数？"。

养成**逐数字扫描**的习惯，能大幅提升鱼形技巧和翼形技巧的发现率。

### 1.3 关注"稀疏"区域

候选数越少的格，蕴含的信息量越大。一个只剩 2 个候选数的格（双值格）是一个天然的逻辑节点——它天然形成强链关系。识别技巧时，优先关注双值格密集的区域。

## 二、基础技巧的识别（第 0-1 层）

这些技巧应当在每一步都自动检查，它们构成了所有后续推理的基础。

### 2.1 唯一候选数（Naked Single）

**识别方式**：某个格经过行列宫的排除后，只剩一个候选数。

**扫描方法**：不需要特别扫描——每次填入一个数字后，自然更新相关格的候选数，唯一候选数会自动浮现。

### 2.2 隐性唯一数（Hidden Single）

**识别方式**：某个数字在某行、某列或某宫中，只有一个位置可以放。

**扫描方法**：逐数字扫描。对每个数字 1-9，检查它在每行/列/宫中的可能位置。如果某个数字在某约束单元中只有一个可能位置，就是隐性唯一数。

> **提示**：隐性唯一数比唯一候选数更难发现，因为它要求你从约束单元的视角而非格的视角来观察。建议在卡壳时系统性地过一遍每个数字在每个约束单元中的分布。

### 2.3 裸对与隐对（Naked / Hidden Pair）

**识别方式**：

- **裸对**：某约束单元中有两个格都恰好包含相同的两个候选数 {A, B}。则这两个候选数被"锁定"在这两个格中，该约束单元其他格的 A 和 B 可以排除。
- **隐对**：某约束单元中有两个候选数 A 和 B，它们只出现在相同的两个格中（但这两个格可能还有其他候选数）。则这两个格的其他候选数可以排除。

**裸对的扫描方法**：在基础排除后，检查每个约束单元中是否有多格共享相同的候选数子集。裸对关注"格的候选数是否相同"——如果两个格都恰好只有 {A, B}，就是裸对。裸对相对容易发现，因为双值格在候选数标注中非常醒目。

**隐对的扫描方法**：隐对比裸对难得多，因为它的识别需要从**候选数的视角**而非**格的视角**出发。多数人的直觉是"看一个格有哪些候选数"，而隐对要求你"看两个数字落在哪些格"。以下是几种实用的识别策略：

#### 双数字交叉扫描法

这是最直接的隐对识别方法：

1. 选一个约束单元（行/列/宫），优先关注剩余空格较多（4-6 个）的单元。
2. 取数字 A，标出它在该单元中的所有候选位置。
3. 取数字 B，标出它在该单元中的所有候选位置。
4. 如果 A 和 B 的候选位置**完全重合且恰好是 2 个格**，就构成了隐对。

关键是**逐对数字检查**，而不是逐格检查。

#### 利用互补关系反推

隐对和裸集是**互补**的。一个单元中如果存在隐对 {A, B} 在格 X、Y 中，那么该单元**剩余的格**必然构成一个关于其他 7 个数字的裸集。

> **为什么必然互补**：隐对和鱼形是同一个定理的两次落地。把二分图的两侧取为"候选数"和"格"，隐对就是数字子集 {A, B} 的候选位置恰好覆盖 2 个格——一个**紧集**；紧集的补集同样紧，所以剩下的 7 个数字必然锁在剩下的 7 个格里，构成裸集。同理，这条链也解释了"双数字交叉扫描法"为什么有效：它检查的正是紧集条件。完整推导见[《数独高级技巧的底层原理》](./sudoku-advanced-techniques.md)的 2.4 节。

实操思路：

1. 先找"隐性唯一"的候选数分布——某数字在某单元中只出现在 2-3 个位置。
2. 再看另一个数字是否也**恰好**只出现在同样的位置。
3. 如果是，就找到了隐对。

#### 优先扫描宫

实践中，**宫内找隐对比行/列更容易**，因为：

- 宫只有 9 个格，信息密度高。
- 宫的边界在视觉上更明确，候选数分布更容易整体把握。
- 很多隐对出现在宫中而非行列。

建议扫描顺序：**先宫，再行列**。

#### 关注候选数密集的格

隐对所在的格通常有 3-5 个候选数（因为还混着其他数字）。如果某单元中有几个格候选数都偏多，这些格更可能藏着隐对。相反，双值格和三值格参与隐对的概率较低。

#### 标注习惯的优化

如果用纸笔标注候选数，可以尝试对每个宫用小标记记录每个数字**出现在哪几个格**（而非在每个格里列候选数）。这种"数字→位置"的视角天然适合发现隐对。如果用数独 App，可以切换颜色标注模式，每个数字用不同颜色标记其候选位置，同一段颜色重叠的区域就是隐对的候选。

### 2.4 区块排除（Pointing / Claiming）

**识别方式**：

- **Pointing**：某数字在某宫中的候选位置全部落在同一行（或同一列），则该行（列）其他宫位置的该数字可以排除。
- **Claiming**：某数字在某行（列）中的候选位置全部落在同一宫，则该宫其他位置的该数字可以排除。

**扫描方法**：观察某数字在某宫内的分布是否"偏置"到某一侧，或在某行/列的分布是否"集中"到某一宫。

## 三、鱼形系列的识别（第 2-3 层）

鱼形技巧的核心是**某数字在 k 行中的候选位置恰好覆盖 k 列**（或反过来）。识别的关键在于逐数字扫描其行列分布。

### 3.1 X-Wing（X 翼）

**识别信号**：

> 某个数字在**两行**中，都恰好只出现在**相同的两列**。

**快速识别步骤**：

1. 选一个数字 d。
2. 找出 d 在每一行中的候选位置数量。
3. 如果恰好有两行中 d 都只出现在 2 个位置，检查这 2 个位置是否落在相同的列上。
4. 如果是，则这两列中其他行的 d 可以排除。

**视觉特征**：四个候选位置形成一个矩形的四个顶点，像一个"X"的两条对角线。

**示例**：数字 7 在第 2 行只出现在 r2c3 和 r2c8，在第 6 行只出现在 r6c3 和 r6c8。则第 3 列和第 8 列中其他行的 7 都可以排除。

### 3.2 Swordfish（剑鱼）

**识别信号**：

> 某个数字在**三行**中的候选位置覆盖**恰好三列**。

**快速识别步骤**：

1. 与 X-Wing 类似，但放宽条件：每行中 d 可以出现在 2 个或 3 个位置。
2. 关键是所有候选位置覆盖的列数 ≤ 3。
3. 如果恰好覆盖 3 列，则这 3 列中其他行的 d 可以排除。

**与 X-Wing 的区别**：X-Wing 要求每行恰好 2 个位置，Swordfish 允许每行 2-3 个位置，只要总覆盖列数 ≤ 3。

### 3.3 Jellyfish（水母）

**识别信号**：

> 某个数字在**四行**中的候选位置覆盖**恰好四列**。

识别方式同理。Jellyfish 在实际解题中较为罕见，因为模式较大，人眼难以直接捕捉。

### 3.4 鱼形技巧的统一识别策略

与其分别记忆 X-Wing、Swordfish、Jellyfish 的模式，不如用一个统一的扫描流程：

1. 对每个数字 d，列出它在每一行中的候选列位置。
2. 寻找那些候选位置数量 ≤ 4 的行。
3. 检查这些行的候选列集合是否存在子集覆盖关系——即 k 行的候选列并集大小 ≤ k。
4. 如果存在，就构成了一个 k 维鱼形技巧。

> **注意**：鱼形技巧可以行列互换。如果按行扫描找不到，可以按列扫描——在某列中 d 的候选行位置覆盖恰好 k 行。

### 3.5 Fin 型鱼（Fin Fish）

当候选位置不完全落在 k 列中，而是多出一两个"鳍"（fin）时，排除范围缩小到与鳍同宫的交叉区域。

**识别要点**：先尝试识别"纯"鱼形，如果发现差一两个位置，检查这些多余位置是否与鱼形的某个交叉点在同一宫中。如果是，则可以在该宫范围内做排除。

**为什么排除范围必须缩小**：多出一列意味着这组行装不进 k 列（亏量 1），"鳍里那个 d 为真"就成了另一种合法可能。被排除的格必须在"鳍为真"和"鱼覆盖成立"两种情形下都不可能是 d，所以它得同时看见全部 k 列**和**所有的鳍——范围只会缩小。这就是 Hall 定理的亏量形式，推导见[《数独高级技巧的底层原理》](./sudoku-advanced-techniques.md)的 2.4 节。

## 四、翼形系列的识别（第 2-3 层）

翼形技巧的核心是**双值格之间的逻辑关联**。识别的关键在于找到候选数只有 2-3 个的格，并检查它们之间的连接关系。

### 4.1 XY-Wing

**识别信号**：

> 三个双值格形成"轴+两翼"结构：轴格 = {X, Y}，翼格1 = {X, Z}，翼格2 = {Y, Z}。轴格同时"看到"两个翼格，但两个翼格之间不一定互相看到。

**快速识别步骤**：

1. 找到一个双值格作为候选"轴"，候选数为 {X, Y}。
2. 找到与轴格在同一约束单元中的另一个双值格，候选数为 {X, Z}（共享 X）。
3. 找到与轴格在同一约束单元中的另一个双值格，候选数为 {Y, Z}（共享 Y）。
4. 如果存在这样的三格组合，则同时看到两个翼格的任何格不能是 Z。

**视觉特征**：三个双值格形成一个"Y"字形结构，轴在中心，两翼展开。

### 4.2 XYZ-Wing

**识别信号**：

> 与 XY-Wing 类似，但轴格有三个候选数 {X, Y, Z}，两翼分别为 {X, Z} 和 {Y, Z}，且三格必须在同一个宫内。

**与 XY-Wing 的区别**：轴格多一个候选数 Z，排除范围更严格（必须三格同宫），但排除目标更明确（Z 从同宫其他格中排除）。

### 4.3 W-Wing

**识别信号**：

> 两个双值格的候选数完全相同 {X, Y}，它们通过数字 X（或 Y）的**强链**连接——即某约束单元中 X 只出现在两个位置，分别包含这两个格。

**快速识别步骤**：

1. 找到两个候选数相同的双值格 A 和 B，都是 {X, Y}。
2. 检查是否存在某个约束单元，其中 X 只出现在两个位置，且这两个位置分别"看到" A 和 B。
3. 如果是，则同时看到 A 和 B 的格不能是 Y。

**与 XY-Wing 的区别**：W-Wing 不要求两翼共享一个"轴"，而是要求两个相同候选集的格通过强链间接连接。

### 4.4 翼形技巧的统一识别策略

1. 标记所有双值格（只有 2 个候选数的格）。
2. 在双值格之间寻找"共享候选数"关系——两个双值格如果有一个共同的候选数，且在同一约束单元中，就形成了一条边。
3. 在这个"双值格图"中，XY-Wing 是一个长度为 2 的路径（轴-翼1，轴-翼2，且两翼共享另一个候选数）。
4. W-Wing 是两个相同候选集的双值格通过强链连接。

## 五、唯一性技巧的识别（第 2-3 层）

唯一性技巧依赖于"数独有唯一解"的元假设，识别方式与其他技巧不同——它寻找的是**危险模式**。

### 5.1 Unique Rectangle（唯一矩形）

**识别信号**：

> 四个格形成矩形（两行两列交叉），其中三个格的候选数都是 {X, Y}，第四个格的候选数包含 {X, Y} 及其他数字。

**快速识别步骤**：

1. 扫描棋盘，寻找候选数恰好为 {X, Y} 的格。
2. 如果找到多个这样的格，检查是否存在两行两列的交叉排列。
3. 如果三个角都是 {X, Y}，第四个角包含 {X, Y, ...}，则第四个角必须取非 {X, Y} 的值。

**视觉特征**：矩形的三个角标记了相同的两个候选数——这是一个"几乎致命"的模式，因为如果第四个角也是 {X, Y}，数独就会有多解。

**常见变体**：
- 如果第四个角除了 {X, Y} 外还有其他候选数，则该角取其他值。
- 如果矩形的一条边上所有格都在同一宫内，可以利用宫内的额外约束来扩展排除。

### 5.2 BUG + 1

**识别信号**：

> 几乎全盘每个未解格都恰好只有 2 个候选数，且每个候选数在每个约束单元中恰好出现两次——只有一个格例外，它有三个候选数。

**快速识别步骤**：

1. 当解题进入尾声，大部分格都已解决时，观察未解格的候选数数量。
2. 如果几乎所有未解格都是双值格，检查是否达到了 BUG 状态（每个候选数在每个约束单元中出现恰好两次）。
3. 如果只有一个格有三个候选数，则该格必须取"第三个"候选数（不在 BUG 模式中的那个）。

**实用价值**：BUG+1 在实战中非常有用，因为它提供了一个"终局检测器"——当棋盘接近解完时，可以快速判断是否进入了 BUG 状态并立即得出答案。

## 六、ALS 的识别（第 3 层）

### 6.1 基本识别

**识别信号**：

> 某约束单元中，N 个格恰好有 N+1 个不同的候选数。

**快速识别步骤**：

1. 在每个行/列/宫中，数一下未确定格的数量和候选数的总数。
2. 如果 N 个格有 N+1 个候选数，这就是一个 ALS。
3. 最简单的 ALS 是裸对（2 格 3 候选数）——等等，裸对是 2 格 2 候选数（Locked Set），ALS 是 2 格 3 候选数。

**常见形态**：
- 3 个格有 4 个候选数
- 4 个格有 5 个候选数
- 5 个格有 6 个候选数

### 6.2 ALS-XZ 规则的识别

1. 找到两个 ALS（A 和 B）。
2. 检查它们是否有"排斥数字" X——X 在 A 和 B 中都出现，且 A 和 B 有格在同一约束单元中（X 不能同时在 A 和 B 的同一约束单元格中成立）。
3. 检查它们是否有"结果数字" Z——Z 同时在 A 和 B 中出现。
4. 如果满足条件，Z 可以从同时看到 A 和 B 中 Z 候选位置的格中排除。

**识别难点**：ALS 的识别本身不难，但找到两个有耦合关系的 ALS 需要一定的搜索成本。建议先从较大的 ALS（4-5 格）开始，因为它们更常见。

## 七、链式推理的识别（第 4-5 层）

当所有模式技巧都无法取得进展时，链式推理是通用的兜底方案。

### 7.1 Simple Colors（简单着色）

**识别信号**：

> 对某个数字 d，存在一系列强链关系，形成一条可追踪的链。

**快速识别步骤**：

1. 选一个数字 d。
2. 找到 d 在某约束单元中只出现在两个位置——这是一条强链。
3. 从这两个位置出发，沿其他约束单元的强链继续扩展。
4. 对链上的格交替标记两种颜色。
5. 如果同色的两个格在同一约束单元中相遇，则该颜色对应的假设导致矛盾，另一种颜色正确。
6. 或者，如果某个未标记格同时看到两种颜色的格，则该格不能是 d。

**适用场景**：当某个数字的强链网络比较丰富时（即该数字在多个约束单元中都只出现在两个位置），Simple Colors 特别有效。

### 7.2 AIC（Alternating Inference Chain）

**识别信号**：

> 强链和弱链交替连接形成一条链，链的首尾可以对某个候选数产生排除。

**快速识别步骤**：

1. 从一个候选位置出发，沿强链走到另一端。
2. 从那里沿弱链走到下一个位置。
3. 再沿强链走，交替进行。
4. 如果链的终点与起点"汇合"（对同一候选数产生约束），则得到排除结论。

**与 Simple Colors 的关系**：Simple Colors 是 AIC 的特殊情况——只使用单一数字的强链。AIC 允许混合不同数字的强链和弱链，因此更通用但也更难识别。

**实用建议**：AIC 的搜索空间很大，人脑直接追踪长链容易出错。建议：
- 先尝试短链（3-5 个节点）。
- 优先使用双值格作为链的节点（它们的强链/弱链关系最清晰）。
- 利用"汇合链"思路：从同一个假设出发走两条路，看是否得出相同结论。

### 7.3 Nishio 法与试错法

**识别信号**：

> 所有模式技巧和链式推理都无法取得进展。

**方法**：选择一个只有两个候选数的格，假设其中一个为真，然后进行推理（不限于链式推理，可以使用任何逻辑）。如果推导出矛盾，则该候选数为假。

**何时使用**：当且仅当所有其他技巧都失效时。从计算复杂性的角度看，数独是 NP 完全的，某些极端困难的题目确实需要搜索。

## 八、系统化识别流程

将上述内容整合为一个完整的解题流程：

### 第一步：基础扫描（每步必做）

```
对每个未解格：
  - 检查唯一候选数 → 直接填入
对每个数字 1-9：
  - 检查每行/列/宫 → 寻找隐性唯一数
  - 检查区块排除（Pointing / Claiming）
对每个约束单元：
  - 检查裸对、隐对、裸三、隐三
```

### 第二步：模式扫描（卡壳时执行）

```
对每个数字 1-9：
  - 列出该数字在每行/列中的候选位置
  - 检查 X-Wing（2行×2列）
  - 检查 Swordfish（3行×3列）
扫描所有双值格：
  - 寻找 XY-Wing 结构
  - 寻找 W-Wing 结构
扫描候选数分布：
  - 寻找 Unique Rectangle
  - 检查是否接近 BUG 状态
```

### 第三步：高级扫描（仍卡壳时执行）

```
寻找 ALS：
  - 在各约束单元中识别 N 格 N+1 候选数的结构
  - 检查 ALS 之间的耦合关系
对每个数字：
  - 尝试 Simple Colors 着色
尝试构建短 AIC
```

### 第四步：搜索（最后手段）

```
选择双值格，假设其中一个候选数
进行推理直到矛盾或突破
```

## 九、识别能力的提升

快速识别不是天生的，而是通过刻意练习培养的。以下是一些提升建议：

### 9.1 建立视觉记忆

每种技巧都有其视觉特征。通过大量练习，你会逐渐对这些视觉模式形成"直觉"：

- X-Wing 的矩形四顶点
- XY-Wing 的 Y 字形三格
- Unique Rectangle 的"三个角标记相同"
- BUG+1 的"全盘双值格"

### 9.2 使用候选数标注

所有中级以上的技巧都依赖于完整的候选数标注。建议使用数独 App 或纸笔标注所有候选数，这是模式识别的前提。

### 9.3 逆向练习

找一道已经解出的数独，从终盘回溯，观察每一步使用了什么技巧。这比正向解题更容易识别模式，因为你知道答案。

### 9.4 分难度训练

- **入门**：只做需要第 0-1 层技巧的题目，直到基础扫描成为自动反应。
- **中级**：加入鱼形和翼形技巧的识别训练。
- **高级**：练习 ALS 和 AIC 的识别。

## 十、总结

快速识别的核心在于：

1. **遵循成本递增的扫描顺序**——先做低成本的检查，再尝试高成本的推理。
2. **以数字为线索**——多数中级技巧都以特定数字的分布为识别起点。
3. **关注双值格和稀疏区域**——它们是逻辑关联最密集的地方。
4. **建立视觉模式的直觉**——通过大量练习，将模式识别从"有意识搜索"转化为"无意识感知"。

掌握识别能力，比掌握技巧本身更重要。一个能迅速判断"此刻该用什么技巧"的解题者，远比一个知道所有技巧但不知从何下手的人更高效。
