# 暗黑破坏神 II：重制版｜死灵法师从零开荒速查

> 路线：骷髅战士 / Raise Skeleton → 伤害加深 / Amplify Damage + 尸体爆炸 / Corpse Explosion → 骷髅支配 / Skeleton Mastery → 地狱稳定推进。  
> 这是以骷髅战士为核心的**召唤死灵**。开荒不依赖固定等级洗点；任务点按实际取得时间分配。更新：2026-10-07。

## 路线总览

| 阶段 | 核心动作 | 当前目标 |
| --- | --- | --- |
| 普通前期 | 召骷髅、上伤害加深 | 骷髅战士数量成形，拿到第一具尸体 |
| 普通中后期 | 首具尸体 → 尸体爆炸连锁 | 为 Boss 准备黏土石魔与衰老 |
| 噩梦 | 骷髅战士与骷髅支配补满 | 佣兵帮忙制造第一具尸体，尸体爆炸负责群怪 |
| 地狱 | 保持召唤群、诅咒、尸爆循环 | 慢慢推进免疫区；以稳定清怪区域刷装备 |

召唤死灵的主要节奏是**先有一具尸体，再用尸体爆炸清场**。尸体爆炸造成物理与火焰伤害，增加技能等级主要扩大范围；它需要牙 / Teeth 作前置。[Blizzard 尸体爆炸说明](https://classic.battle.net/diablo2exp/skills/necromancer-poison.shtml)。

## 30～70 级：骷髅支配与尸爆范围

| 时期 | 技能（中文 / English） | 停止条件 |
| --- | --- | --- |
| 复生骷髅满 20 后 | 骷髅支配 / Skeleton Mastery | 补到 20 硬点 |
| 两项骷髅技能成形后 | 尸体爆炸 / Corpse Explosion | 先加到范围用得顺手，约 10～15 硬点，之后可补 20 |
| 噩梦和地狱任务奖励 | 骷髅支配或尸体爆炸 | 按任务实际完成时间投入 |
| 仍有余点 | 复活 / Revive、微暗灵视 / Dim Vision、更多尸爆或召唤辅助 | 根据地图与操作习惯补 |

**复活 / Revive**是可选的后期一击点，不要在 30 级以为它没有前置：需要骷髅法师 / Raise Skeletal Mage、血石魔 / Blood Golem 和钢铁石魔 / Iron Golem 等前置。点数紧张时先把骷髅战士、骷髅支配和尸体爆炸做好，后面再补复活。[Blizzard 召唤技能表](https://classic.battle.net/diablo2exp/skills/necromancer-summoning.shtml)。

伤害加深与衰老都属于诅咒，后施放的诅咒会覆盖先前诅咒。普通怪群用伤害加深配尸爆；危险精英或 Boss 改用衰老、黏土石魔减速。尸爆没有尸体时无法启动，佣兵与骷髅的首杀速度很重要。

## 属性和洗点

- **力量 / Strength：** 按当前武器、盾和衣服门槛加。水晶剑 / Crystal Sword 要 43，阔剑 / Broad Sword 要 48。
- **敏捷 / Dexterity：** 本路线先不走高格挡，仅按当前装备要求补。
- **精力 / Energy：** 通常不追加。早期缺蓝多带药水，后期洞察佣兵解决回蓝。
- **体力 / Vitality：** 其余全部投入，自己站远些仍须防突进与远程伤害。

**普通阿卡拉第一次洗点可先留着。** 召唤路线从普通到地狱不用强制换流派；点错了或想转骨矛 / Bone Spear、毒系时再洗。噩梦、地狱各有一次免费洗点，完成邪恶洞窟后可留用。三次用完还可集齐地狱四类精华合成赦免徽记 / Token of Absolution。[重置资料](https://classic.battle.net/diablo2exp/skills/basics.shtml)。

拿到君主盾 / Monarch 后若要做精神盾，力量要求 **156**。召唤死灵无需把精神盾视为唯一目标：带 +召唤技能、抗性或格挡的死灵专用盾也可能更合适。真决定换君主盾，再按其他装备提供的力量计算基础力量；不必提前加满。

## 地狱推进、Boss 与佣兵

1. **开局找尸体：** 让骷髅与佣兵集中攻击同一目标；第一具尸体出现后，上伤害加深并连放尸体爆炸。
2. **打 Boss：** 保持黏土石魔贴近 Boss，施放衰老；佣兵有压碎性打击时打 Boss 更快。石魔死了及时重召。
3. **免疫怪：** 伤害加深能降低物理抗性，但不是所有物免都能解除；尸爆有物理与火焰两部分。物免、火免同时很难处理的非任务怪可以绕过。
4. **狭窄地形：** 召唤物容易堵路，改变站位或使用带传送聚气的法杖聚怪。用聚气传送要留意维修花费与落点安全。
5. **刷图选择：** 适合清大片怪群和地狱牛场等能持续获得尸体的区域；不把法师的高频传送刷劳模效率作为自己的门槛。

第二幕噩梦进攻型**力量 / Might**光环可提高队伍物理输出，帮助制造首具尸体；洞察满足回蓝需求。若佣兵地狱站不住，先查等级、抗性、头盔吸血和武器底材伤害。PC 默认 `Shift + 药水快捷键` 可给佣兵用药。换佣兵前取回原佣兵装备。[Blizzard 佣兵说明](https://classic.battle.net/diablo2exp/basics/hirelings.shtml)。
