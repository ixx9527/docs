# 第一次做龙井虾仁

四年级的周记，题目是"我做了一道菜"，要求写出制作过程，200 字。夏末写的是做龙井虾仁。

这一篇分四部分：原稿、修改后的版本、修改建议、注意事项。**老师这次还没批改**，所以没有红笔批注可对照——下面的修改建议全部按上次《我的超市达人——奶奶》那 36 处红笔里立的标准来提，只当预演，不是评分结论。

---

## 一、原稿

<div class="essay-body">

今天，我决定大显身手，做一道龙井虾仁。

我走进厨房，穿上围裙，先将虾仁洗干净，放入 yán（盐）和一点儿胡 jiāo（椒）进行 yān（腌）制，再把龙井茶泡开，然后把油倒进 guō（锅）里，油刚刚"着路"。就发出了一声巨大的响声，我吓的四处逃散。过了一会儿，巨响减 ruò（弱），我才敢小心 xì xì（翼翼）地把虾仁倒进 guō（锅）里，duǒ duǒ 闪闪的翻炒。最后把龙井茶倒进 guō（锅）里。龙井虾仁就大功告成了。

</div>

稿子一个字没动，连她写在拼音后面的括号提示也照原样留着——那个括号很要紧，第三节要说它。先把实测数字摆出来：

| 实测项 | 数字 |
| --- | --- |
| 正文字数 | 净汉字 123 个，连标点约 155 字（要求 200，差 40～50 字） |
| 拼音顶替 | 11 处，涉及 7 个不同的字 |
| "的／地／得" | 全文 4 处，写对 2 处、写错 2 处 |
| 错别字 | 1 处（着路 → 着陆） |
| 标点 | 1 处（"着路"后的句号把一句话砍断） |
| 同一个动词重复 | "倒进锅里"用了 3 次 |
| 周记抬头 | 日期、星期、天气、题目，四样全缺 |

## 二、修改后的版本（补足 200 字）

先说一句实话：只改字词、标点、重复用词和抬头格式，字数反而从 155 掉到 145——因为顺手删掉了"进行腌制""巨大的响声"这类冗字。<strong>改字省不出字数，缺的那 40～50 字只能长在镜头里。</strong>所以下面这一版把四个空着的追问补上了，实测 **230 个格子**（汉字 199、标点 31；要求 200 字，四年级作文字数一般按下限算，多 30 格不是废话）。

<div class="essay-body">

＿＿月＿＿日　星期＿＿　天气＿＿

第一次做龙井虾仁

今天，我决定大显身手，做一道龙井虾仁。

我走进厨房，穿上围裙，把虾仁洗干净，用漏勺沥干水，加一点儿盐和胡椒腌一会儿；再把龙井茶泡开，滤出茶汤，茶叶留在杯底。

锅烧热，倒油。油刚刚"着陆"，锅里就"刺啦"炸开了——原来锅底还有水。油花蹦到手背上，烫得我甩手往后躲。

等响声小了，我才敢小心翼翼地把虾仁滑进锅里，躲躲闪闪地翻炒：锅铲举得老高，胳膊伸得长长的。虾仁从透明变成粉红，边上卷起小圈，这才算熟了。我把茶汤浇进去，翻两下关火，一股茶香飘出来。

端上桌，我剥了一只，先是鲜，咽下去才有一点儿茶香。

</div>

### 补进去的六句，全是我替她加的

这些句子按龙井虾仁的正常做法推出来，**看着顺，但不一定是她当时真看见的**。誊之前要逐句问她一遍：她记得的画面如果和这里不一样，**一律用她的，哪怕比我这句短、比我这句笨**。

| 补进去的句子 | 我的依据 | 要问她什么 |
| --- | --- | --- |
| 用漏勺沥干水 | 虾仁必须沥干；这也正是"巨响"的来源 | 当时到底沥没沥？ |
| 滤出茶汤，茶叶留在杯底 | 茶叶久煮发苦，一般只取汤 | 家里下锅的是茶汤还是连茶叶一起？谁滤的？ |
| 锅里就"刺啦"炸开了——原来锅底还有水 | 水遇热油才炸 | 响的到底是油下锅那一下，还是虾仁下锅那一下？ |
| 油花蹦到手背上，烫得我甩手往后躲 | 替换"四处逃散" | 真被烫到了吗？躲到哪儿去了？有没有喊人？ |
| 虾仁从透明变成粉红，边上卷起小圈 | 虾仁成熟的判断点 | 你当时看见变色了吗？ |
| 剥了一只，先是鲜，咽下去才有一点儿茶香 | 结尾要有结果 | 什么味？谁先吃的？爸爸评价了吗？ |

真要压回 200 整，删两处细节就行，各不影响过程完整：「，胳膊伸得长长的」减 8 格、「，茶叶留在杯底」减 7 格，余 215。

## 三、修改建议

### 逐条对照

| 原文 | 问题出在哪 | 建议改成 |
| --- | --- | --- |
| yán（盐）、jiāo（椒）、yān（腌）、guō（锅）×3、ruò（弱）、xì xì（翼翼）、duǒ duǒ | 11 处拼音顶替 | 括号里的汉字直接写进正文，见下面单独说 |
| 放入盐和胡椒 | "放入"用在整件的东西上，粉末该用"加／撒" | 加一点儿盐和胡椒 |
| 进行腌制 | 大人话。上次她写"不仅仅"，老师往轻了改 | 腌一会儿 |
| 油刚刚"着路"。 | "着陆"写成了同音的"路"；句号还把句子砍断了 | 油刚刚"着陆"， |
| 发出了一声巨大的响声 | "巨大的响声"是概括，不是声音 | "刺啦"一声 |
| 我吓的四处逃散 | 的／得错；"逃散"的主语必须是一群人，一个人不能逃散 | 我吓得直往后躲 |
| 巨响减 ruò（弱） | 油不会"巨响减弱"，逻辑不通 | 响声小了 |
| 小心 xì xì（翼翼）地把 | 这个"地"她自己写对了 | 保留，当标杆 |
| duǒ duǒ 闪闪的翻炒 | 的／地错，动词前用"地" | 躲躲闪闪地翻炒 |
| 把油倒进锅里／虾仁倒进锅里／茶倒进锅里 | 同一结构用三次。上次"精打细算"用两遍，老师把第二个换成了"节俭" | 油淋进锅、虾仁滑进锅、茶汤浇进去 |
| 全篇只有"先／再／然后／最后" | 概括链，没有一处慢镜头 | 见下面四个追问 |

### 拼音涨了，但性质变了

上次的 6 处拼音，她是真写不出来。这次 11 处，**每一个后面都用括号补上了汉字**——盐、椒、腌、锅、弱、翼、躲，这 7 个字她全认得，只是手上没练过默写。

所以补法完全不同：不用重新分析字形，把这 7 个字各默写三遍，誊清时括号一个不许留。当天就能做完。

### 详略是倒的，过程还断在三环上

要求写制作过程，她的笔墨分配是：准备工作（穿围裙、洗虾仁、放盐）两句，真正要命的下锅那 30 秒——也两句。按上次老师说的"该细的地方细"，这儿正该反过来：准备一句带过，关键那一步放慢镜头。

而且龙井虾仁有三个环节她整段跳过了：**虾仁洗完要沥干**（这恰好就是"巨响"的来源）、**茶要泡开取汤**、**虾仁变色就出锅**。缺一环，别人照着她这段文字就做不出来。

### 四个地方空着，得她自己回厨房补

| 位置 | 要问她什么 | 为什么这儿必须有字 |
| --- | --- | --- |
| "我吓得四处逃散"之后 | 锅是不是没擦干？水进了热油才会炸 | 响声是有原因的，把原因写出来，全篇最好的素材就活了 |
| "再把龙井茶泡开"之后 | 下锅的是茶汤还是湿茶叶？谁滤的？ | 读者分不清，过程就断了关键一环 |
| "躲躲闪闪地翻炒"之后 | 虾仁什么时候算熟？颜色怎么变的？ | 写做法必须有判断点，不然不知道何时关火 |
| "大功告成了"之后 | 端上桌谁吃的？尝一口什么味？ | 少了结果，结尾只能靠成语撑 |

### 最好的一笔她自己埋掉了

原稿里 `躲躲闪闪的翻炒` 这六个字是全篇唯一真看见了的动作——锅铲举得老高、人往后缩。上次老师红笔补的正是这种"能拍下来的那一秒"（眉头皱起来、眼角弯成月牙）。这次她自己拍到了，却只当"翻炒"的修饰语用掉，一句带过。

**扩写的办法只有一条：对着当时的画面，依次回答眼睛看到什么、耳朵听到什么、手在做什么。** 按这个办法把四个追问各写两三句，200 字自己就到了——第二节那一版就是这么补出来的，实测 230 格。

但那一版**是示范，不是誊清稿**：补进去的六句全是我按龙井虾仁的正常做法推的，她得逐句换成自己当时真看见的东西。上次她的老毛病是"要自己选表达的时候就退回大概对"，要是连镜头都由大人写好，这次要练的那一样又替她代劳了。

### 抬头四样

周记要求写日期、星期、天气、题目，她的稿子直接从"今天，我决定大显身手"起笔，四样一样没有。别小看这一行：写完天气顺手就能接一句当天的事，开头就不会空着。题目她自己没拟，《第一次做龙井虾仁》最直白；也可以用她自己的声音当题目——《厨房里的一声"刺啦"》。

## 四、注意事项

**誊清前自己过四遍，不用家长代劳：**

1. **数拼音。** 全文搜小写字母，必须为 0。这次是 11 处。
2. **搜"的、地、得"。** 逐个问一句：后面是名词用"的"，后面是动词用"地"，动词后面补状态用"得"。她这次"小心翼翼地把"写对了，照那个手感找剩下的两处。
3. **重复的词第二次必须换。** 凡是出现两次以上的动词或漂亮词，换一个说法。
4. **数镜头。** 挑出三句概括句，各换成一个动作、一个声音或一种颜色。改完必须从头连着读一遍——上次老师划掉几个字，语法就跟着断了，光看改动那一处看不出来。

**另外四条给家长：**

- 字数不够**不要靠加形容词凑**，那 40～50 字只能补在四个追问上。
- 「着陆」这类**敢用的词要保住**，只换错字。她分得清这是俏皮话，还自己加了引号，这份语感比"写得规范"值钱。
- 日期和天气**留白让她自己填**，别替她编。
- **老师批回来之后以老师为准。** 若红笔和本页建议不一致，照《我的超市达人——奶奶》那篇的做法，把红笔并进来再出一版，并回头修正这一页的标准。
