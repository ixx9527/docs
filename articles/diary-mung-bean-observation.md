# 绿豆成长记录：从一张观察记录表到一篇观察日记

四年级上册语文的观察作业，原话是「**整理、修改《绿豆成长记录》，完成观察日记**」。这里有两个名字，别混：**「绿豆生长观察记录表」是每天填的日常记录表**，《**绿豆成长记录**》是把六天记录综合、修改之后那篇日记的名字。

这一页分七部分——老师的要求、夏末的观察记录表、**夏末自己改写的版本**、**润色版（要交这份）**、我的参考改写稿、四位同学的范文、对照要求的自查。

夏末那版是 2026-10-24 晚她手写的，我**照原样抄**在第三节（错字、量词、标点不替她改，删掉的东西也不替她补回来）。**有三处她改得比我的稿子好**，还有一处她把原表的错数改对了，我都单独标出来。第四节是**在她这版基础上顺出来的润色版**——她的句子一个字没换，只把她自己删掉的内容放回原处、把必写的第六天补成一篇。我那版降为第五节的参考。

范文是老师挑出来展示的作业，**姓名已全部隐去**，用 A、B、C、D 代替。

## 一、老师的要求

### 题目与体裁

作业题目是**《绿豆成长记录》**——综合六天记录之后写成的那篇**观察日记**。

它的原材料是每天填的**「绿豆生长观察记录表」**（表头印着「观察员：××」）：左边一栏「绘画」画下当天的样子并标出长度，右边一栏「记录」写字。所以这是**两步**，不是一步：先整理、修改记录表里的观察内容，再改写成日记。

### 硬性指标

老师在家长群里的原话，拆成六条可对照的标准：

| 项 | 要求 |
| --- | --- |
| 天数 | 记录表共 6 天；改写日记**不少于 4 天**，其中**第 1 天和第 6 天必须有**，中间 4 次取 2 次。6 次都完整的话全写也可以 |
| 三要素 | 要写出**看到的、闻到的、想到的** |
| 三个变量 | 要写出**颜色、形状、长度**的变化 |
| 手法 | 在观察内容的基础上优化，用**比喻、拟人**等修辞，让文字生动形象 |
| 连贯 | 挑记录时要注意前后内容的连贯 |
| 顺序 | **先对照表格补观察内容，再改写成日记**——不是直接给一篇作文 |

### 印在表格上的提示语

第一天：**种植的心情，种植的方法，绿豆的样子**。

其余各天：**从看到的、听到的、闻到的、想到的等不同角度去观察绿豆。从颜色、长度、外形等不同角度记录绿豆的变化，记录你的心情。**

### 从四篇范文里反推出来的标准

老师的消息只说了原则。把四篇范文摆在一起看，它们不约而同做了同一批事——这大概就是"比较详细"的实际含义：

| 范文共同点 | 四篇里有几篇做到 |
| --- | --- |
| 第一天就写**干绿豆原本的样子**（颜色、大小、软硬、中间那条白线） | 3／4（另一篇只有老师补的"一个圆圆地"） |
| **长度给出具体数字**，且一天一个台阶 | 4／4 |
| 每天都写**看到** | 4／4 |
| 写过**闻到** | 3／4 —— 同学 A 六天里一次都没写味道 |
| **每天都不缺**闻到 | **只有 1／4**（同学 C） |
| 每天写**想到的**或心情 | 4／4 |
| 结尾落在**一句感想或道理**上 | 4／4 |
| 写「听到的」 | **只有 1／4**（同学 A） |

> 上面这些计数是我逐篇数出来的，口径写在右侧——"写过"和"每天都写"是两件事，分开列才看得出真正的差距。分类之间有交叉，数字只用来看倾向，不当评分。

三条值得单独拎出来：

1. **第一天那格不能跳。** 四篇里三篇开头就写干豆子"硬硬的""深绿色""中间一条白白的短线"。夏末这篇直接跳到"放进水里"了，把印表第一条漏掉了。
2. **"听到的"这一格可以放弃。** 只有同学 A 用了它，而且她是把整篇都架在"我仿佛听到它们……"这一句上。其余三位都没写，不算缺。
3. **"没有味道"也算写到了闻到。** 同学 B 第二天写"闻不到特别的味道"——这一格就填上了，不必硬编一股香味。

**第一天　周五**

我满怀期待的把绿豆放进水里，像一个个小精灵跳进碗里，沉睡在水里。睡前，它们涨的大大的，吸饱水的绿豆就不能在泡了。我把水倒了出来。

**第二天　周六**

第二天早上，我惊喜的发现大部分绿豆都发芽了①，而且有的还 tuō 掉了绿色的外套，露出白白胖胖的身体。它们的身体像 kā fei 豆一样，都由二瓣组成。抓一把，还能闻到一缕淡淡的清香。

**第三天　周日**

绿豆长得可真快呀！过去了 1 天，已经长了快 1cm 长了！长出来了芽的底部渐渐变成了 zǐ 色，而且豆的大小大了不少。香味也从清香变到了幽香。老远都能闻到

图示：1.9cm（最长）

**第四天　周一**

放学，我回来大惊失色地发现绿豆们都 dā 拉着 nǎo 袋①。我急忙开始对它们进行一 fàn 抢救，我先把被压扁的绿豆挑了出来，因为装它们的容器太小了，所以被压在下面的绿豆扁了，再把它们放进一个更加宽 kuò 的盘子，最后我在网上查了查，发现它们"dā拉着脑袋是因为"没加水，于是我往盘子里放了好多水，我急切的等待着它们复活。

①一幅死气沉沉的模样

**第五天　周二**

绿豆的生命力可真强！第二天，大部分绿豆都活了过来，而且底部又发了另一 niè 牙，和另一个不同，它们长出来的是叶子，嫩绿嫩绿的，像刚刚长出来的茶叶。

**第六天　周三**

绿豆们已经 jiě 体了，原来的两辨完全分开，上下两头芽连成了一条线，且上面芽的顶部已经变成了 jiāo 黄色。绿豆也没有原来那么硬了，变的软软的。

### 一处订正：第二天的「1mm」是原表笔误

上面照原样抄，**没有替她改**。但第二天绘画栏那个 `1mm（最长）` 写错了，**实际是 1 厘米**。这条是家长 2026-10-24 回签确认的，而且它一订正，第三天的账才算得通：

> 第二天 1 厘米 →「过去了 1 天，长了快 1 厘米」→ 第三天整根 1.9 厘米。
> 1 ＋ 0.9 ≈ 1.9。**原来那个 1mm 会让第三天的增量算不出来**——从 1 毫米一天长到 1.9 厘米，不是"快 1 厘米"。

所以这一处不是她记错了，是**誊写时把单位写错了**。她自己在改写稿里反而把这个数改对了（见第三节脚注①）。

**绿豆观察日记**

**10月16日　星期五　晴**

这是我观察绿豆的第一天，回家后把绿豆们放进水里泡发。一个个小绿豆穿着绿色的紧身衣，静静地在水里做着美梦，睡前，"错误认识"告诉我要把水倒掉。

**这个错误认识闯了祸**

**10月17日　星期六　阴**

第二天早上，我发现大部分绿豆已经发了芽①，而且还脱掉了绿色的紧身衣，露出白白胖胖的身体，它们的身体跟咖啡豆很像，——都由二瓣组成，而且还散发着一缕细微的香味，断断续续，若有若无。真期待这些绿豆们快快长大。

**10月19日　星期一　雨**

两天过去了，绿豆们一点儿也没长，这可把我急坏了。我在网上查了查，才知道原来是因为缺水，我急忙把他们放进水里。又把他们放到阳光最好的阳台上，希望我的补救能成功。

**10月20日　星期二　晴**

放学后，我去查看了我的绿豆，大部分绿豆都缓了过来②，但还是一幅病怏怏的状态，哎，可惜啦，这些绿豆最终还是没有如愿长成一片树林。

①最长的有1厘米
②两瓣豆子分裂开了，茎也长到了2cm。

「这个错误认识闯了祸」在她纸上**单独成一行，笔迹明显更重更大，而且没写句号**——她自己知道这句重要。

### 她改得比参考稿好的四处

| 她的原句 | 为什么算更好 |
| --- | --- |
| **「这个错误认识闯了祸」** | **全篇最值钱的一处。** 原表里"第一天把水倒掉"和"第四天长不好"是两格互不相干的记录，她自己把它们焊成了一条因果线。参考稿靠"小精灵"串修辞，她这条是**事实层面的因果**——老师要的"前后连贯"，她这条比我那条硬。 |
| 「一缕细微的香味，**断断续续，若有若无**」 | 参考稿停在"淡淡的清香"（那是原表的原话）。她这八个字写的是**气味的状态**：不是一直有，是一阵一阵。四篇范文里没有一处这样写过味道。 |
| 日期＋星期＋天气（10月16日 星期五 晴） | 观察日记的格式感。参考稿用"第一天 周五"，她换成真实日期，天数就站住了。 |
| 结尾**敢写失败**：「还是没有如愿长成一片树林」 | 四篇范文里三篇落在"大自然真奇妙""生命力可真强"。她这句是**没如愿**。观察日记最容易写成"一切都很好"，她没有。 |

还有一处不算"改得好"，算**她把我抓不到的错抓到了**：小注①写的是「最长的有 1 厘米」，而原表绘画栏图注是 `1mm`。**是原表写错了**——只有第二天 1 厘米，第三天的"长了快 1 厘米"和"整根 1.9 厘米"才同时成立。我第一版照抄了 1mm，她改成了 1 厘米。参考稿已按她的订正改过来。

### 长度这条线，她的数比参考稿更真

小注②「茎也长到了 2cm」在原表里找不到出处，我一度以为她记混了。把日期对上，不是：

> 第三天 1.9 厘米（10/18）→ 断水 → **第五天 2 厘米（10/20）**。中间隔了两天，只长了 1 毫米。

这正好印证她自己那句「两天过去了，绿豆们一点儿也没长」。**一条笔直上涨的长度线反而是假的**——她这条在断水那两天趴了一下，那个"趴"就是观察结果本身。

所以长度这项，两版合起来才完整：**1 厘米（二）→ 1.9 厘米（三）→ 2 厘米（五，趴住）→ 9 厘米（今天）**。

### 还缺什么

| 问题 | 说明 |
| --- | --- |
| **第六天没有单独成篇** | 唯一可能被扣分的硬伤。她写了第 1、2、4、5 天，**第 6 天被压成小注②**。删第三天合规（中间四天取两天），第 6 天不合规——老师点名必须有。而②的内容（两瓣分裂）本来就是第六天的观察，**把它提成一篇就行，不用新增任何内容**。 |
| 第四天被写平了 | 原表第四天是她情绪最强的一天：「大惊失色」「耷拉着脑袋」「一幅死气沉沉的模样」。改写后只剩「一点儿也没长」——**"闯了祸"到底闯出什么祸，没写出来**。把"耷拉着脑袋"加回来，既是她的原话，又正好是断水的后果。 |
| 钩子甩出去没接住 | 「这个错误认识闯了祸」单独成行、笔迹加重，后面却再没回它一句。第五天或第六天补半句「都是那个错误认识闯的祸」，这条线就闭合了。 |
| 颜色线断了 | 删第三天，连带丢了「芽的底部渐渐变成了紫色」——那是全篇唯一的颜色变化，也正是今天那根 9 厘米紫茎的来头。 |
| 少了两个比喻 | 第五天「像刚刚长出来的茶叶」、第二天脚注「很像小女孩的马尾辫」都没进改写稿。现在全篇有豆、有紧身衣、有树林，**唯独没有一片叶子**。 |
| 换宽盘子被删 | 原表第四天最像范文的一段是"发现问题—动手处理"：挑出压扁的→换宽盘子→上网查→加水。她只留下"上网查→加水"。 |
| 搬到阳台这条要问她 | 「又把他们放到阳光最好的阳台上」原表里没有。真搬了就留着，那是她的观察；顺手加的就删。（顺带：发豆芽其实不宜暴晒，范文里有一位专门写"盖上纸遮光"。） |
| 结尾和第五天相抵 | 第五天写"大部分缓了过来"，结尾写「**最终**还是没有如愿长成一片树林」。家长已说明这两句想说的是**第六天当时还没恢复生气、今天是重新缓过来了**——意思不冲突，冲突的是"最终"这个**词**，它把一时写成了结局。润色版删掉"最终"，并在「写到这里」补一句"它们又缓了过来"，两句各归各的时间 |

### 用字（五处，都好改）

| 她写的 | 应为 | 说明 |
| --- | --- | --- |
| 都由**二**瓣组成 | 两瓣 | 原表就这么写，没改过来 |
| 一**幅**病怏怏 | 一**副** | 量词 |
| 病**怏怏** | 病**恹恹** | 怏怏是"不高兴"，恹恹才是"没精神" |
| 把**他们**放进水里／放到阳台上 | 把**它们** | 同篇里"它们的身体"用对了，这两处滑回"他们" |
| 跟咖啡豆很像**，——**都由二瓣组成 | 去掉逗号 | 破折号前不叠逗号 |

标题她写的是《绿豆观察日记》，作业名是《绿豆成长记录》——差一个字的事，提醒一下。

**绿豆成长记录**

**10月16日　星期五　晴**

这是我观察绿豆的第一天。回家后把绿豆们放进水里泡发。一个个小绿豆穿着绿色的紧身衣，小小的，硬硬的，静静地在水里做着美梦。

**10月17日　星期六　阴**

第二天早上，我发现大部分绿豆已经发了芽，最长的有 1 厘米，而且还脱掉了绿色的紧身衣，露出白白胖胖的身体。有的芽卷卷地翘起来，很像小女孩扎的马尾辫。它们的身体跟咖啡豆很像，都由两瓣组成，而且还散发着一缕细微的香味，断断续续，若有若无。真期待这些绿豆们快快长大。

**10月19日　星期一　雨**

两天过去了，绿豆们不但一点儿也没长，还都耷拉着脑袋，一副死气沉沉的模样。这可把我急坏了——都是那个"错误认识"闯的祸呀！

**绿豆成长记录**

**第一天　周五**

今天，我开始种绿豆了。

它们小小的，硬硬的，穿一身深绿色的外衣，摸上去光光的，中间还有一条白白的小短线。

我满怀期待地把绿豆放进碗里，倒上水。一颗颗绿豆像一个个小精灵，跳进碗里，安安静静地沉睡过去了。

睡觉前我又跑去看它们。呀，它们已经涨得大大的，绿色的外衣被撑得紧紧的。吸饱了水的绿豆不能再泡水，我把水倒了出来。

小精灵们，好好睡吧。

**第二天　周六**

第二天早上，我惊喜地发现，大部分绿豆都发芽了！

它们脱掉了绿色的外套，露出白白胖胖的身体。有的芽又白又尖，卷卷地翘起来，很像小女孩扎的马尾辫——最长的也才 1 厘米。它们的身体像咖啡豆一样，都由两瓣组成。

我伸手抓了一把，还能闻到一缕淡淡的清香。

昨天还沉睡的小精灵，今天全都醒过来了。

**第三天　周日**

绿豆长得可真快呀！才过去一天，芽就长了快 1 厘米，最长的那一根，整根量已经有 1.9 厘米了。

芽的底部渐渐变成了紫色，豆子也大了不少。香味也变了，从昨天的清香变成幽香，不用凑近，老远都能闻到。

**第四天　周一**

今天放学回家，我大惊失色——绿豆们都耷拉着脑袋，一副死气沉沉的模样。

我急忙给它们来了一番"抢救"。先把被压扁的绿豆挑出来，装它们的容器太小了，压在下面的都被压扁了；再把它们搬进一个更加宽阔的盘子；最后我上网查了查，原来它们耷拉着脑袋，是因为没加水。

我赶紧往盘子里放了好多水，急切地等待着它们复活。

**第五天　周二**

绿豆的生命力可真强！过了一天，大部分绿豆都活了过来，脑袋又抬起来了。

它们的底部又发了另一根嫩芽。和之前不一样的是，这次长出来的是叶子，嫩绿嫩绿的，像刚刚长出来的茶叶。

**第六天　周三**

绿豆们已经"解体"了。原来的两瓣完全分开，上下两头芽连成了一条线，上面那头的芽尖已经变成了焦黄色。

我伸手摸了摸，绿豆再也没有原来那么硬了，变得软软的。

我盯着看了好久，忽然明白过来：原来小豆子长大，是要把自己拆开的呀。豆瓣不要了，外衣也不要了，全都拿去长芽了。它们再也不是那颗硬硬的小绿豆，可我替它们高兴。

**写到这里**

今天我又去量了一次，最长的那一根，已经有 9 厘米了。我凑近闻了闻，是一股豆香，还带着一点草香。而它刚下水的时候，还是一颗硬硬的小绿豆。

</div>

## 六、同学范文

四位同学的记录表。为便于阅读，**明显的笔误已径改**，没有逐字保留原稿的错别字和拼音——这一页要学的是他们怎么写，不是他们写错了什么。老师用红笔划线的句子，在下面「写得好的地方」里引出来。

### 同学 A（六天）

<div class="essay-body">

**第一天**　周一早上，我满怀期待地拿出绿豆，正准备放入土里，外婆却把我拦住了。她细心地告诉我绿豆怎么种，我终于明白了，绿豆与其它植物不一样，它是种在水里的，因此绿豆不需要浇水也不需要施肥。我兴致勃勃地把绿豆放入了水中。

**第二天**　第二天一早，我又跑来看我的绿豆，绿豆大了不少，皮上有一道裂痕，我仿佛听到了它在对我打招呼，想到了它们长大后的样子，我不由得一阵兴奋与期待涌上心头。这时，我脑子里又冒出个念头：它的长度改变了吗？我立刻量了量，呀，长了 1 倍，让我体会到了绿豆生命力强。

**第三天**　第三天到了，我迫不及待地去看看我的绿豆有什么新变化，不看不知道，一看吓一跳，绿豆都已经长出了短短的白芽，一个个绿豆像好奇宝宝一样四处张望着打探世界，可爱极了，我仿佛听到了它们在讨论这世界。可我一想到这绿豆以后会怎样我就十分好奇，总想看到它长大的一面。

**第四天**　周四大早，我便起来看我的绿豆了，一个绿豆又长了许多，一个白白嫩嫩的芽十分有劲像一个大力士，已经成为豆芽了，头上的芽慢慢开始变黄，看上去成熟了不少，我仿佛还听到了它们在比谁更高更壮呢，这使我更期待了。

**第五天**　已经第五天了，豆芽长得更长，更高了，还长出了嫩绿的小叶子，十分可爱，我拿出尺子量了量豆芽的长度，呀，又长高了不少，芽也越来越白了，此时，与第一天比它已经成巨人了，我仿佛听到了它们在议论着谁高谁低，谁胖谁瘦，它们议论得十分热烈。

**第六天**　第六天也是观察的最后一天，豆芽已经长出了大大的绿油油的叶子，十分引人注目，身高也高了不少，我拿起豆芽看看底部，底部已扎上了牢固的根，豆芽已经长到了 7 厘米了，相当于一开始的约 8 倍，我仿佛听到它们在说这世界的美丽，有的在比谁的叶子大，有的还在努力生长，让我明白了小小的生命也能有大大的力量。

</div>

**写得好的地方**

- **一根线穿六天。** 她每天都写一句"我仿佛听到它们……"——打招呼、讨论世界、比谁更高更壮、议论谁高谁低、在说世界的美丽。老师在这五句下面全部划了线。这一招把"想到的"从"偶尔想起来写一句"变成了**每天都有固定出口**，六天自然就连贯了。
- **长度用倍数，不只会用厘米。** "长了 1 倍""相当于一开始的约 8 倍"——比单说"7 厘米"更能让人感觉到变化有多大。
- **结尾落一句道理。** "小小的生命也能有大大的力量"。四篇范文里只有她落在道理上，其余三位落在感叹上。

### 同学 B（六天）

<div class="essay-body">

**第一天**　今天我挑选了一把圆圆的、绿油油的绿豆。我找来一个盘子，铺上一层湿纸巾，把绿豆均匀摆好，再盖上一张湿润的纸巾。一颗颗绿豆硬硬的，穿着深绿色的外衣，中间还有一条白白的短线。我心里充满期待，真盼望它们快点发芽！

**第二天**　一早我就跑去观察绿豆。绿豆喝饱了水，圆滚滚的，比昨天胖了一大圈，深绿色的外衣被撑得发亮，有的已经裂开了一条小缝，露出里面白白的肚皮。纸巾湿湿的，闻不到特别的味道。我心里又惊喜又激动，盼着小芽赶紧钻出来。

**第四天**　今天的绿豆又长长了不少，大约有一厘米，芽儿白白嫩嫩的，弯弯地翘起来。原来的豆瓣向两边撑开，颜色慢慢变浅，摸上去软软的。我也去闻了闻，清香味比昨天更明显了。看着一棵棵努力向上生长的小嫩芽，我心里充满成就感，真期待它们长出小叶子！

**第五天**　今天豆芽已经有 2 厘米了。白嫩嫩的茎挺得直直的，圆鼓鼓的豆瓣慢慢向两边分开，中间探出一点点嫩黄的小叶片。凑近闻一闻，除了豆香，还有淡淡的青草味。看着它们努力向上生长，我满心期待，真希望小叶子快点舒展开！

**第六天**　绿豆苗已经长到大约 3 厘米啦！之前嫩黄的小叶慢慢变成清新的淡绿色，两片小叶子彻底张开，就像一对小巧可爱的翅膀。白色的茎也变得更加粗壮结实。看着这一颗颗充满生命力的小苗，我十分惊喜，真没想到一颗小小的绿豆，竟然可以长出这样鲜嫩的叶，大自然真是太奇妙了！

</div>

**写得好的地方**

- **第一天就把干豆子写全了。** "硬硬的，穿着深绿色的外衣，中间还有一条白白的短线"——软硬、颜色、形状，三样一句话带过。这正是夏末漏掉的那一格，可以照着补。
- **"闻不到特别的味道"。** 第二天她老实写没味道，这一格照样算填上了。**观察日记里"没有"也是一种观察**，比编一股香味诚实得多。
- **长度是三个台阶。** 一厘米 → 2 厘米 → 3 厘米，一天一个数，变化一眼看得见。
- **比喻都取很小的东西。** 芽像"小小的逗号"，叶子像"一对小巧可爱的翅膀"。不取"像大树""像春天"这类空话，所以读着具体。
- 五感是**轮换**着写的：第一天看＋摸，第二天看＋摸＋闻（没味道），第三天看＋摸＋闻（清香），每天侧重不一样，就不会六天写成一句话重复六遍。

### 同学 C（记了七天）

<div class="essay-body">

**第一天**　今天，我开始种绿豆。我把一粒粒椭圆的、中间白旁边绿的绿豆放到碗里，再在下面铺一张湿的纸巾，这样能持续给绿豆水分。没过多久，有几粒豆子就像气球一样鼓起来了，可能是要发芽了。我盖上盖子，把它放在避光处。我真期待它长大！（图示：3 毫米）

**第二天**　今天我打开盖子，一股浓浓的豆香就扑面而来。我一看，呀！这些豆子好像比昨天大了一两毫米，而且颜色变淡了一点，也更圆润了。我又在纸上喷了点水，再把它放搁子里。我一边忙，一边想：我的小豆豆呀！你什么时候才能长成豆芽啊！一天才长这么一点，不会一周还长不大吧！（图示：5 毫米）

**第三天**　今天，我看到一粒粒绿豆都长出小白芽啦！我发现，豆子还没有裂开，闻起来像豆浆的味道。我量了量这嫩白的小芽，发现它已经有 5 毫米长了。我想：一天就长了这么多，真厉害呀！我继续给它盖上纸遮光，盼着豆芽快快生长。（图示：5 毫米）

**第四天**　今天是第四天，我打开纸和盖子，发现每个绿豆都裂开了，露出里面的嫩芽，这时我开心极了。但一闻，发现一股臭味。刚刚的开心全都烟消云散了，我十分担心它生病，于是拿掉了盖子，给它通风。我许下心愿：豆芽，你一定要健康长大！

**第五天**　今天，我看到每一粒绿豆的芽都长长了，这是非常好的表现！不过，有一颗绿豆似乎一点也没长大，还黏黏的，我怀疑它生病，于是，我把它夹出来扔掉了。我再把其它豆子分散开，这样可以让它长得更壮。我又闻了闻，昨天的臭味都没了，可能是我把盖子拿走的缘故吧。我给它喷了点水继续避光，让它能好好长大。

**第六天**　今天，我看到这些小芽都像树枝一样长出了好多小细根，我高兴坏了。不过，垫在下面的纸巾已经发黄了，我赶紧把所有豆子拿出，把纸换掉，再在上面喷上水。我又闻了下，发现只有水的味道，我就放心了。现在，这些豆芽的芽已经有 1 厘米多一点长了，不仅比原来变大了，还长出了细根，想到这里，我十分开心。

**第七天**　今天，我又看了看豆子，发现它们的芽长得很长了，有 3 厘米呢！我又闻了闻，有一点豆花的味道，这说明了豆子没事。它们的颜色变淡了，嫩芽还更白了，我很高兴。有一些豆子上长了树枝一样的细根，不过它们都很短，只有 5—6 毫米。喷了点水后，我想，一颗绿豆这么有生命力，没几天就能长大，大自然真奇妙！

</div>

**写得好的地方**

- **七天里味道一直在变，而且变坏了。** 豆香扑面而来 → 像豆浆 → **一股臭味** → 只有水的味道 → 豆花的味道。四篇范文里只有她写了"泡臭了"。观察日记最容易写成"一切都很好"，她这一条最真实，老师划线的句子也最多。
- **有一条"发现问题—动手处理"的动作线。** 发现臭味→拿掉盖子通风；发现一颗没长大还黏黏的→夹出来扔掉；豆子挤了→分散开；纸巾发黄→换纸。**这条线是另外三位都没有的**，它让日记有了情节，不只是照片。
- **数字最密。** 3 毫米 → 一两毫米 → 5 毫米 → 1 厘米多 → 3 厘米，第七天还补了一句"细根只有 5—6 毫米"，连根都量了。
- 夏末第四天那条"抢救"线（挑出压扁的→换宽盘子→上网查→加水）和同学 C 这条是同一类东西——**这是她全文最像范文、也最该保住的一段**。

### 同学 D（六天）

<div class="essay-body">

**第一天**　今天，我把几颗圆圆的绿豆放入杯中。它们小而硬，身着绿色外衣，摸起来光滑又结实。我先往杯子中倒了一些温水，绿豆们争先恐后地沉入水底，像在水底睡觉。我心想：小豆子，你们快喝水快长大吧！我给它们盖上一层"小被子"，希望它们快快长大。

**第二天**　一大早，我跑去看绿豆。哇！它们像被施了魔法一样，变得圆鼓鼓的，比昨天整整"胖了一圈"，皮被撑得紧紧的，有几颗甚至撑破了一角，露出了里头白嫩嫩的豆瓣。我用手指碰了碰，软软的，和昨天硬邦邦的感觉完全不一样，闻了一闻，有一股淡淡的豆香。

**第三天**　好几颗绿豆都长出了白芽，弯弯的，尖尖的，像一条条尾巴探出头来，最长的都有两厘米了，豆瓣的颜色也随之变浅，从深绿变浅绿，外壳很皱，水也不再清澈。我闻了闻，清新的味儿更浓了，我多么希望它长大呀！

**第四天**　今天的绿豆芽的变化让我大吃一惊！白白的小芽变直了，茎又细又长，大约有三四厘米高。豆瓣中间冒出一根嫩黄的小芽尖，像两只小手掌正要往两边张开。底部的根须越来越多，密密麻麻地缠绕在纸上，凑近闻一闻，一股清香飘了过来。

**第五天**　放学回到家我第一时间冲去看绿豆芽，它们又长高了一大截！最高的差不多有八厘米了！顶端的叶子微微张开，像一只蝴蝶准备起飞，根须也更加茂密了，紧紧地贴在杯壁上。我拿起尺子认真量了量，兴奋地叫了起来——最高的那株竟然有十厘米啦！看着这些豆芽越长越大，我心中满是成就感。

**第六天**　今天是观察的最后一天，两片嫩绿的叶子完全张开，椭圆形的叶片像两只绿色的小手在迎接阳光，茎变得更粗壮了，颜色也从白色变为淡紫色，所有绿豆芽都笔直地立着，整整齐齐，杯底的根须交错环绕，像一张白色的网。我闻了闻，空气中弥漫着淡淡的青草香，六天前的豆子，现在已经变成了一片小森林了，生命的力量太神奇了！

</div>

**写得好的地方**

- **第一天的四件套最标准。** "小而硬，身着绿色外衣，摸起来光滑又结实"——大小、软硬、颜色、触感，一句话写完，正好是夏末第一天缺的那格。
- **比喻最密，而且成串。** 争先恐后沉入水底像睡觉 / 被施了魔法 / 像一条条尾巴 / 像两只小手掌 / 像一只蝴蝶准备起飞 / 像一张白色的网。
- **结尾那句是四篇里最好的。** "六天前的豆子，现在已经变成了一片小森林"——用"六天前"和"现在"对照，变化一句话就立住了。夏末改写稿结尾"而它刚下水的时候，还是一颗硬硬的小绿豆"用的是同一个办法。
- **长度数字给得狠。** 两厘米 → 三四厘米 → 八厘米 → 十厘米，还写了"兴奋地叫了起来"，数字和心情绑在一起，不是干报数。
- 反过来也提醒一句：**辞藻越密，越要先保证字词写对。** 她这篇老师给了红五角星，但也是四篇里笔误最多的（"水低""豆辨""迷漫"）。先把字写对，再堆比喻，顺序不能反。

**三版的关系**：因果线、气味的真实度、敢写失败——这三样**只有她有**，润色版全部原样保住；天数齐全和颜色线完整是我的参考稿的优势，润色版**用她自己的材料把第六天补上了**（脚注②＋原表第六天），但**紫色没有硬塞回去**，因为第三天是她主动删的。

**交之前只剩一处要她本人填**：**10 月 21 日的天气**——我不知道，留了空。

结尾那处已经定了。家长说明这两句要表达的是**第六天当时还没恢复生气，今天是重新缓过来了**——意思本来不冲突，冲突的是「最终」这个词，它把一时写成了结局。润色版删掉「最终」，并在「写到这里」补一句「它们又缓了过来」（用的是她第五天自己的词），时间层次一分开，两句都是真话。

**唯一的真缺口**：**第四、五、六天的气味**。家长已确认回忆不起来，而缺的是观察本身，观察已经过期——这一格只能空着，不编。
