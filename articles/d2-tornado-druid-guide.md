# 暗黑破坏神 II：重制版｜德鲁伊从零开荒速查

> 路线：火风暴 / Firestorm → 裂地之火 / Fissure → 约 30～35 级洗点为龙卷风 / Tornado + 飓风 / Hurricane。  
> 适合单人从零推进普通、噩梦，进入地狱后以风德继续通关和刷怪。技能点按任务实际取得时间灵活分配。更新：2026-10-07。

## 路线总览

| 阶段 | 主要输出 | 当前目标 |
| --- | --- | --- |
| 普通 1～11 级 | 火风暴 / Firestorm，熔浆巨石 / Molten Boulder | 拿经验、完成邪恶洞窟，准备 12 级 |
| 普通 12～30 级 | 裂地之火 / Fissure | 推进剧情，准备知识头、精神剑底材 |
| 约 30～35 级 | 第一次阿卡拉洗点转风德 | 龙卷风负责物理伤害；飓风提供冰冷伤害和减速 |
| 噩梦 | 龙卷风、飓风、旋风护甲 | 补满核心技能与抗性，佣兵装备洞察 |
| 地狱 | 风德成型后推进与刷图 | 处理免疫组合，优先稳定击杀而非强堆 MF |

风德移动速度不等于法师传送。跑图时利用橡木智者的生命加成、旋风护甲和佣兵挡怪；需要跨地形时可在商店寻找带传送聚气的法杖，但要计算维修费用。

## 2～29 级：火系开荒

表中只安排**升级所得**技能点。普通难度任务奖励单列，不要求刚好在表中某一级完成。

| 等级 | 技能（中文 / English） | 说明 |
| --- | --- | --- |
| 2～5 | 火风暴 / Firestorm ×4 | 前期主攻 |
| 6 | 熔浆巨石 / Molten Boulder ×1 | 裂地之火前置；可推开怪物 |
| 7～11 | 火风暴 / Firestorm ×5 | 等待 12 级主技能 |
| 12～29 | 裂地之火 / Fissure ×18 | 对成群、移动中的怪效果好 |

| 普通难度任务 | 奖励 | 此阶段建议 |
| --- | --- | --- |
| 邪恶洞窟 / Den of Evil | +1 技能、一次免费重置 | 投火风暴 |
| 罗达门特 / Radament | +1 技能 | 投裂地之火；若还未到 12 级，先留着 |
| 衣卒尔 / Izual | +2 技能 | 按实际进度投裂地之火或火风暴；裂地之火每个可用角色等级有投入上限 |

**打法：** 裂地之火放在怪群的行进路径上，等它们走过火口；冷却期间补火风暴或熔浆巨石。纯火技能在噩梦后段遇到火免会越来越难用，这就是转风德的主要原因。裂地之火需要火风暴和熔浆巨石各至少 1 点。[技能前置见 Blizzard 技能表](https://classic.battle.net/diablo2exp/skills/druid-elemental.shtml)。

### 洗点前的属性

- **力量 / Strength：** 只满足正在使用的衣服、盾和武器；水晶剑 / Crystal Sword 要 43，阔剑 / Broad Sword 要 48。
- **敏捷 / Dexterity：** 本路线先不走格挡，仅在当前装备确实要求时补。
- **精力 / Energy：** 默认不加；缺蓝可临时加少量，第一次洗点收回。
- **体力 / Vitality：** 其余全部投入。

## 约 30 级：第一次洗点转风德

用普通难度邪恶洞窟的免费重置。以下是 **30 级且已拿齐普通难度 4 个任务点**时的一套 **33 硬点**配置；若任务未做齐，从旋风护甲和小旋风的额外点数中扣。

| 技能（中文 / English） | 硬点 | 作用 |
| --- | ---: | --- |
| 极地风暴 / Arctic Blast | 1 | 风系前置 |
| 旋风护甲 / Cyclone Armor | 12 | 吸收火、冰、电伤害，并协同龙卷风 |
| 小旋风 / Twister | 11 | 风系前置与协同 |
| 龙卷风 / Tornado | 7 | 主要物理输出；24 级解锁，30 级最多 7 硬点 |
| 飓风 / Hurricane | 1 | 30 级解锁，周身冰冷伤害与减速 |
| 橡木智者 / Oak Sage | 1 | 提高生命上限，阵亡后及时重召 |
| **合计** | **33** | **升级 29 + 普通任务 4** |

不要把龙卷风误认为冰伤：**龙卷风是物理伤害，飓风是冰冷伤害**。旋风护甲吸收的是火、冰、电伤害，不能代替抗性、生命与走位。龙卷风的轨迹不笔直，瞄准怪物背后连续施放通常比只点击怪物更容易命中。[Blizzard 技能说明](https://classic.battle.net/diablo2exp/skills/druid-elemental.shtml)。

## 31～70 级：技能推进

| 来源或等级 | 技能（中文 / English） | 结果 |
| --- | --- | --- |
| 31～43 级，共 13 点 | 龙卷风 / Tornado | 7 → 20 |
| 44～62 级，共 19 点 | 飓风 / Hurricane | 1 → 20 |
| 63～70 级，共 8 点 | 旋风护甲 / Cyclone Armor | 12 → 20 |
| 噩梦任务点，取得时分配 | 小旋风 / Twister 或橡木智者 / Oak Sage | 要伤害投协同，要更高生命投橡木智者 |
| 后续升级与地狱任务点 | 小旋风 / Twister | 逐步补到 20 |

这是**升级点**顺序；噩梦和地狱任务奖励另计。若进噩梦时觉得旋风护甲太薄，可先补它，再把飓风补满。最终主要技能为龙卷风 20、飓风 20、旋风护甲 20、小旋风 20，橡木智者至少 1；点数不够时先保持核心输出与生存。

实战先维持橡木智者、旋风护甲和飓风，再用龙卷风输出。飓风 1 点时主要用于减速，等级高后清杂兵更有效。纯物免怪可让飓风与佣兵尝试处理；物免与冰免同时存在且难以击杀时，绕开非任务目标。

## 属性和三次洗点

| 时点 | 力量 / Strength | 其余属性 |
| --- | --- | --- |
| 第一次洗点后 | 只满足当前武器和防具 | 敏捷、精力不追加；其余体力 |
| 拿到君主盾 / Monarch 后 | 含其他装备加成达到 156 | 可用噩梦阿卡拉第二次洗点精确调整，也可用储存点补足 |
| 后期想转火德、召唤德等 | 按新装备重算 | 地狱阿卡拉第三次洗点留给大改流派 |

不要在尚无君主盾时提前投入大量力量。每个难度的邪恶洞窟各提供一次免费洗点，完成后可留着以后使用；三次用完后可以在地狱收集四种精华合成赦免徽记 / Token of Absolution 再洗。[任务与重置说明](https://classic.battle.net/diablo2exp/quests/rewards.shtml)。

## 符文之语与装备优先级

| 装备（中文 / English） | 符文顺序 | 底材和用途 |
| --- | --- | --- |
| 隐秘 / Stealth | Tal + Eth | 2 孔衣服；施法速度与跑速 |
| 古代人的契约 / Ancient's Pledge | Ral + Ort + Tal | 3 孔盾；早期抗性 |
| 精神剑 / Spirit Sword | Tal + Thul + Ort + Amn | 4 孔剑；+2 技能、25～35% FCR |
| 知识 / Lore | Ort + Sol | 2 孔头盔；+1 技能；有风系技能加成的德鲁伊头底材更好 |
| 洞察 / Insight | Ral + Tir + Tal + Sol | 4 孔合适的佣兵武器；回蓝 |
| 押韵 / Rhyme | Shael + Eth | 2 孔盾；抗性、MF |
| 烟雾 / Smoke | Nef + Lum | 2 孔衣服；全抗 +50 |
| 精神盾 / Spirit Shield | Tal + Thul + Ort + Amn | 4 孔君主盾；需 156 力量，地狱阶段再考虑 |

符文必须按顺序放入正确孔数、正确类型的普通品质底材；魔法、稀有、套装和暗金物品不能做符文之语。普通牛场掉的白色无孔水晶剑交拉苏克可打成 4 孔；其他掉落地点的水晶剑结果可能不同。白色无孔君主盾交拉苏克可打 4 孔。[Blizzard 符文之语](https://classic.battle.net/diablo2exp/items/runewords-110.shtml)、[盾牌底材](https://classic.battle.net/diablo2exp/items/elite/shields.shtml)。

优先顺序：**足够抗性和生命 → +技能与施法速度 → 佣兵武器 → MF**。如果已有带 +龙卷风 / +飓风的德鲁伊专用头盔，与知识头比较实际技能总量再决定，不必机械地只看符文之语名称。

## 地狱推进与佣兵

1. 普通、噩梦先以裂地之火快速清怪。转风德后练习龙卷风瞄准，并保持飓风和旋风护甲常驻。
2. 第二幕佣兵可持洞察。若佣兵在地狱容易倒，先看等级、抗性、头盔生命偷取和洞察底材伤害；给他烟雾衣服或可用的抗性装备。
3. 地狱遇到强物免时利用飓风、佣兵或绕路。没有传送技能，跑图效率通常不如法师；选择清怪路线和自己稳定的区域。
4. 安达利尔、墨菲斯托可以尝试，但别照搬暴风雪法师的传送与卡河节奏。适合风德的刷图标准是**能安全抵达并稳定击杀**。
