# 暗黑破坏神 II：重制版｜野蛮人从零开荒速查

> 路线：重击 / Bash → 双手挥击 / Double Swing → 24 级解锁狂乱 / Frenzy → 双武器推进地狱。  
> 这是**近战狂乱野蛮人**路线。武器底材、命中和生命偷取会直接决定地狱推进速度；第一次洗点按实际拿到的武器类型决定，不必卡在 30 级。更新：2026-10-07。

## 路线总览

| 阶段 | 目标 | 决策点 |
| --- | --- | --- |
| 普通 1～23 级 | 双手挥击开荒，准备两把可用单手武器 | 先拿双手挥击、狂乱前置和早期战吼 |
| 普通 24～40 级 | 狂乱开始接管输出 | 补战斗体制；升级两把武器，不只升级主手 |
| 噩梦 | 狂乱、战斗体制与武器专精逐步成型 | 缺命中、伤害、吸血就停下来换底材与装备 |
| 地狱 | 稳定清怪后再刷固定区域 | 物免用狂战士技能或绕过；不要照搬法师的刷劳模路线 |

野蛮人是装备驱动的近战职业。**狂乱吃两把武器的实际伤害与命中率**；即使技能点照表加，拿普通难度低伤害武器直接进入地狱也会打得很慢。战斗体制能提高生命、法力和耐力，但仍需抗性和生命偷取。[Blizzard 技能说明](https://classic.battle.net/diablo2exp/skills/barbarian-combatskills.shtml)。

## 2～29 级：双手挥击转狂乱

下表只安排升级所得的技能点，普通任务点另列。武器专精只给**当前双武器共同使用的类型** 1 点，尚未确定后期武器时先不要点满。

| 等级 | 技能（中文 / English） | 说明 |
| --- | --- | --- |
| 2 | 重击 / Bash ×1 | 双手挥击前置 |
| 3～5 | 当前武器专精 ×1；狂嗥 / Howl ×1；重击 ×1 | 先拿命中和战吼前置 |
| 6 | 双手挥击 / Double Swing ×1 | 双持主攻 |
| 7～11 | 双手挥击 ×5 | 优先提高早期输出 |
| 12 | 双手投掷 / Double Throw ×1 | 狂乱前置，不要求使用投掷武器 |
| 13 | 嘲弄 / Taunt ×1 | 战斗狂嗥前置，也是狂乱协同 |
| 14 | 大叫 / Shout ×1 | 战斗体制前置 |
| 15～17 | 双手挥击 ×3 | 继续主攻 |
| 18 | 战斗狂嗥 / Battle Cry ×1 | 降低目标防御与伤害，打 Boss 好用 |
| 19～23 | 双手挥击 ×5 | 等待狂乱开放 |
| 24 | 狂乱 / Frenzy ×1 | 需要装备两把可用武器 |
| 25 | 战斗体制 / Battle Orders ×1 | 提高生命、法力、耐力上限 |
| 26～29 | 狂乱 ×4 | 开始提高主攻技能 |

**前置确认：** 狂乱需要重击、双手挥击、双手投掷；战斗体制需要狂嗥和大叫。战斗狂嗥需要狂嗥与嘲弄。把技能点暂时存着，到达开放等级后再点也可以。[战斗技能](https://classic.battle.net/diablo2exp/skills/barbarian-combatskills.shtml)、[战吼技能](https://classic.battle.net/diablo2exp/skills/barbarian-warcries.shtml)。

| 普通难度任务 | 奖励 | 建议去向 |
| --- | --- | --- |
| 邪恶洞窟 / Den of Evil | +1 技能、一次免费重置 | 寻找药剂 / Find Potion；在需要前可先存点 |
| 罗达门特 / Radament | +1 技能 | 寻找物品 / Find Item，前置为寻找药剂，需角色 12 级 |
| 衣卒尔 / Izual | +2 技能 | 钢铁皮肤 / Iron Skin ×1、自然抵抗 / Natural Resistance ×1；后者需角色 30 级 |

任务奖励不一定按这个时间到手。未到技能开放等级就存点，或先投当前主技能并在第一次洗点时重排。**寻物技能用于增加击杀后的额外掉落机会，不负责战斗输出。**

## 30 级以后：技能优先级与第一次洗点

30 级先给**战斗指挥 / Battle Command** 1 点；它提高队伍技能等级，战斗前先使用，再施放战斗体制。若普通衣卒尔任务点已拿到，可按前表补钢铁皮肤和自然抵抗；自然抵抗需要钢铁皮肤作前置。[战吼](https://classic.battle.net/diablo2exp/skills/barbarian-warcries.shtml)、[战斗专精](https://classic.battle.net/diablo2exp/skills/barbarian-combatmasteries.shtml)。

接下来按以下**优先级**分配，不机械绑定角色等级：

1. **狂乱 / Frenzy → 20：** 主攻技能；双手挥击的旧点数以后仍给它提供伤害协同。
2. **战斗体制 / Battle Orders → 20：** 近战生存核心。若感觉太脆，可与狂乱交替投入。
3. **当前武器专精 → 20：** 只在确定长期双持剑、斧或锤等某一类武器后再大量投入。两把武器类型不同，专精不能同时覆盖两把。
4. **剩余点数：** 双手挥击与嘲弄是狂乱协同；自然抵抗通常先 1 硬点，再看装备抗性决定是否加。寻找物品按刷图偏好投入。

普通阿卡拉的**第一次洗点**可留到你从早期钉头锤/连枷转为中期剑或斧，并确定主要武器底材之后，用来调整武器专精与属性。如果早期误点太散，或双武器不够用，也可提前洗；洗完确保狂乱、战斗体制及前置都能拿到。没有拿到新武器时，无须为了"30 级必须洗点"而洗。

### 物理免疫的备用技能

地狱遇到难绕开的物免怪时，考虑给**狂战士 / Berserk** 1 点。它把攻击转为魔法伤害，但需要先学**击昏 / Stun**和**专心 / Concentrate**等前置；使用时会暂时失去防御加成，别站在怪群里硬砍。无法安全处理的非任务物免直接绕过。[Blizzard 技能表](https://classic.battle.net/diablo2exp/skills/barbarian-combatskills.shtml)。

## 属性和剩余洗点

- **力量 / Strength：** 满足当前武器和防具需求。近战底材门槛可能比法师高，但别为了尚未取得的终局装备提前大量加力量。
- **敏捷 / Dexterity：** 按当前双武器要求补足；命中率低时优先检查角色等级、武器专精、装备命中和目标等级，再决定是否增加敏捷。
- **精力 / Energy：** 不投。法力靠药水、物品与吸取解决。
- **体力 / Vitality：** 剩余全部投入；战斗体制会放大生命池收益。

噩梦阿卡拉第二次洗点可留给确定中后期武器后的精确属性与专精调整。地狱阿卡拉第三次洗点可留给后期狂战士、旋风 / Whirlwind、战吼 / War Cry 等路线。三个难度各有一次免费重置，完成任务后可留用；用完可用地狱四种精华合成赦免徽记 / Token of Absolution。[技能重置资料](https://classic.battle.net/diablo2exp/skills/basics.shtml)。

## 符文之语与武器升级

| 装备（中文 / English） | 符文顺序 | 适用阶段和注意点 |
| --- | --- | --- |
| 钢铁 / Steel | Tir + El | 2 孔剑、斧、锤；普通前期快速获得可用武器 |
| 力量 / Strength | Amn + Tir | 2 孔近战武器；压碎性打击和生命偷取，打 Boss 有用 |
| 荣耀 / Honor | Amn + El + Ith + Tir + Sol | 5 孔近战武器；等级、吸血、伤害；底材必须够好 |
| 黑色 / Black | Thul + Io + Nef | 3 孔棍棒/锤类；压碎性打击；击退词缀可能影响清怪手感 |
| 烟雾 / Smoke | Nef + Lum | 2 孔衣服；全抗 +50，地狱前期稳健 |
| 狮子心 / Lionheart | Hel + Lum + Fal | 3 孔衣服；力量、敏捷、生命和抗性 |
| 执法者 / Lawbringer | Amn + Lem + Ko | 3 孔合适的剑/锤/权杖；可作功能副手，触发衰老 |
| 誓约 / Oath | Shael + Pul + Mal + Lum | 4 孔合适的剑、斧、锤；拿到更高符文与好底材后考虑 |

初期一对钢铁或钢铁加力量可以推进普通；进入噩梦、地狱时必须不断替换**底材基础伤害更高**的武器。狂乱两把武器都会攻击，副手长期拿低伤害普通底材会拖累输出。做符文之语前确认孔数、物品类型和符文顺序；魔法、稀有、套装、暗金物品不能作为底材。不同武器大类的专精不要混淆。[Blizzard 原始符文之语](https://classic.battle.net/diablo2exp/items/runewords-original.shtml)、[1.10 符文之语](https://classic.battle.net/diablo2exp/items/runewords-110.shtml)。

武器以外优先考虑**抗性、生命偷取、命中率、攻速、不能被冻结**。MF 放在能安全击杀之后；双持近战在地狱缺伤害时，即便堆高 MF 也不会刷得快。

## 地狱推进与刷图决策

1. 先检查自己的地狱抗性与命中率，再看普通怪击杀速度；打不动就回噩梦升级武器、等级和佣兵装备。
2. 小怪成群时先用狂嗥驱散、战斗狂嗥削弱，再挑目标建立狂乱攻速。战斗前维持战斗指挥与战斗体制。
3. 难缠物免可用 1 点狂战士或绕开。危险的法系怪、高伤害精英不必硬站撸。
4. **寻找物品 / Find Item** 可对击杀后留下的合适尸体再用一次。地狱女伯爵周边、第一幕适合自己清理的区域可以作为早期目标；崔凡克议会刷法需要更扎实的武器、抗性与火伤应对，留待装备成熟。
5. 刷地狱墨菲斯托的效率不要拿法师作标准。野蛮人的优势是战吼生存和寻物，按实际击杀速度选择区域。

第二幕佣兵的光环、输出和洞察回蓝都有帮助。若他站不住，检查等级、抗性、头盔吸血及武器底材伤害；PC 默认可用 `Shift + 药水快捷键` 给佣兵喝药。更换佣兵前先取回其装备。[Blizzard 佣兵说明](https://classic.battle.net/diablo2exp/basics/hirelings.shtml)。
