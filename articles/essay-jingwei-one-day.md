# 我和精卫过一天

四年级上册的想象习作《我和____过一天》，夏末在习作单上填的是**精卫**。单子上没有老师红笔，只有她自己的铅笔字：五个栏目格、两处写到表格外面去的字，还有一行写完后又整行擦掉的淡痕。

这一页分四部分：**习作单逐字转录**、**连缀成篇**、**润色版**，最后列出这篇里要保住的句子。

| 部分 | 是什么 |
| --- | --- |
| 一、习作单逐字转录 | 按栏目照录铅笔字，错字、标点、擦痕都保留原样 |
| 二、连缀成篇 | 把五个栏目按顺序接成全篇，一个字不改 |
| 三、润色版 | 在连缀版基础上用四年级口吻顺一遍，附逐条改动清单 |
| 四、要保住的句子 | 这篇里她自己写出来的好句子，下次改稿不许动 |

**题目**　我和精卫过一天

**开头**

## 三、润色版

只顺句、订正用字标点、断长句；不新增事例，不补心理描写，不堆成语。她自己写出来的句子一字不动。

<div class="essay-body">

"炎帝之少女，名曰女娃……"我正读着《精卫填海》这篇古文，突然，书本上出现了一个洞，把我吸了进去。过了一会儿，我眨了眨眼，发现我来到了东海。

这时，一只小鸟衔着石子飞了过来。头上有花纹，白色的嘴，红色的脚，长得有点儿像乌鸦。哦！这不就是精卫吗！

我和精卫一起来到东海上空，把石子扔到海上，正准备前往西山。顿时，天空乌云密布，下起了倾盆大雨，能见度直线下降。伴随着一声巨响，一道闪电砸了下来，我吓得到处乱逃。精卫不慌不忙地说："没事，骑上我，咱们去西山。"我们顶着各种狂风暴雨，终于来到了西山。精卫衔起一颗石子就走，我问："你辛辛苦苦来到这里，就为了这颗石头？"精卫答道："不，我不仅仅是为了石子，我想要把东海填平。它曾经夺走了我的生命，我不能让它夺走更多的生命！"

这时，我刚准备回答，却感觉有人在拍我。我一转头，看到的不再是东海，而是熟悉的妈妈和卧室。妈妈问："盯着书看那么久干吗？"我没有回答，回忆着刚刚那段旅程，若有所思……

## 四、这篇里要保住的句子

- **能见度直线下降。** 用说明文式的词写天气突变，比"雨很大"准得多。
- **一个闪电砸了下来。** "砸"是全文最有力的动词，润色只动量词，不动它。
- **它曾经夺走了我的生命，我不能让它夺走更多的生命！** 自己把神话的因果接进故事，是全文的骨架，任何版本都不许改写。
- **若有所思……** 结尾不硬点题、不喊"大自然真奇妙"，留白收住，这是她的胆子。

## 勘误与存疑

1. 「去了哪里、做了什么」栏第二行整行被擦去，仅余淡痕；对比度增强后仍不可辨。转录以〔〕占位，连缀成篇与润色版均不补字。
2. 「我吓的到处乱逃」的"到"与"处"之间有一处淡痕，似擦改残留，按"到处"读。
3. 「红色的脚」后的标点原迹为实心点，判为句号；亦可能为写得较小的逗号。若为逗号，外貌一节应读作一整句。
4. 栏格右边界外溢出的字（"更多的生命！""若有所／思……"）已按语序接回正文，位置不作额外标注。
5. 习作单页眉的校名、班级、姓名栏不进公开页；原图留在本地 `homeworks/我和精卫过一天/`，不进仓库。
