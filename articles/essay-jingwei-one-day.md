# 我和精卫过一天

四年级上册的想象习作《我和____过一天》，夏末在习作单上填的是**精卫**。单子上没有老师红笔，只有她自己的铅笔字：五个栏目格、两处写到表格外面去的字。

这一页分四部分：**习作单逐字转录**、**连缀成篇**、**润色版**，最后列出这篇里要保住的句子。

| 部分 | 是什么 |
| --- | --- |
| 一、习作单逐字转录 | 按栏目照录铅笔字，错字、标点都保留原样 |
| 二、连缀成篇 | 把五个栏目按顺序接成全篇，一个字不改 |
| 三、润色版 | 在连缀版基础上用四年级口吻顺一遍，附逐条改动清单 |

## 一、习作单逐字转录

<div class="essay-body">

**题目**　我和精卫过一天

**开头**

"炎帝之少女，名曰女娃……"我正读着《精卫填海》这篇古文，突然，书本上出现了一个洞，把我吸了进去。过了一会儿，我眨了眨眼，发现我来到了东海。

**中间 · 外貌描写**

这时，一只小鸟衔着石子飞了过来。头上有花纹，白色的嘴，红色的脚。长的有点儿像乌鸦，哦！这不就是精卫吗！

**中间 · 去了哪里、做了什么**

我和精卫一起去到了东海上空，把石子扔到海上，正准备前往西山，顿时，天空乌云密布，天空下起了倾盆大雨。能见度直线下降。伴随着一声巨响，一个闪电砸了下来，我吓的到处乱逃，精卫不慌不忙的说："没事，骑上我，咱们去西山。"我们遇到了各种狂风暴雨。终于来到了西山，精卫衔起一颗石子就走，我问："你辛辛苦苦来到这里，就为了这颗石头？"精卫答道："不，我不仅仅是为了石子，我想要把东海填平，它曾经夺走了我的生命，我不能让它夺走更多的生命！"

**结尾**

这时，我刚准备回答，但感觉有人在拍我，我一转头，看到的不再是东海，而是熟悉的妈妈和卧室，妈妈问："盯着书看那么久干吗？"我没有回答，回忆着刚刚那段旅程，若有所思……

</div>

转录说明：栏格右边界写不下的字（"更多的生命！"与"若有所／思……"）已按语序接回正文。

## 三、润色版

只顺句、订正用字标点、断长句；不新增事例，不补心理描写，不堆成语。她自己写出来的句子一字不动。

<div class="essay-body">

"炎帝之少女，名曰女娃……"我正读着《精卫填海》这篇古文，突然，书本上出现了一个洞，把我吸了进去。过了一会儿，我眨了眨眼，发现我来到了东海。

这时，一只小鸟衔着石子飞了过来。头上有花纹，白色的嘴，红色的脚，长得有点儿像乌鸦。哦！这不就是精卫吗！

## 四、这篇里要保住的句子

- **能见度直线下降。** 用说明文式的词写天气突变，比"雨很大"准得多。
- **一个闪电砸了下来。** "砸"是全文最有力的动词，润色只动量词，不动它。
- **它曾经夺走了我的生命，我不能让它夺走更多的生命！** 自己把神话的因果接进故事，是全文的骨架，任何版本都不许改写。
- **若有所思……** 结尾不硬点题、不喊"大自然真奇妙"，留白收住，这是她的胆子。

## 五、对照魏老师的提醒：成篇要补的三处

家长群里魏老师的提醒（2026-11-01）：和神话或童话中的一个人物过一天，**根据这个人物的特点去设计情节**；可以一起去陌生的神奇世界游历，或一起去需要帮助的地方做一件善事；这当中**会遇到什么困难，是怎么解决的**；文章的选材和立意很重要，构思时得考虑成熟。

逐条对照：

| 魏老师的要求 | 习作单上的表现 | 判断 |
| --- | --- | --- |
| 神话或童话中的人物 | 精卫，出自《精卫填海》 | 符合 |
| 根据人物特点设计情节 | 衔着石子飞、去西山取石、风雨里不停——情节全从"填海"长出来，换个神话人物就不成立 | 符合，是这篇最大的亮点 |
| 游历神奇世界，或去需要帮助的地方做善事 | 帮精卫衔石填海，属"做善事"一路；但"帮"在单子上只有"把石子扔到海上"一句 | 符合，偏薄 |
| 遇到什么困难，是怎么解决的 | 乌云密布、倾盆大雨、闪电砸下；解决是精卫一句"没事，骑上我"，顶风硬过 | 困难有了，解决全在精卫一边，"我"只乱逃和坐鸟背 |
| 选材和立意考虑成熟 | 精卫那句"我不能让它夺走更多的生命"，把填海从报仇抬成护着别人 | 立意立住了，但全由精卫说出口；结尾"若有所思"没接住它 |
| 题目暗含的"一天" | 从被吸进书里到被妈妈拍醒只有一段，没有晨昏痕迹 | 时间线弱，"一天"悬空 |

成篇时补这三处（示例句只是参考，用不用、怎么改由夏末自己定）：

1. **给"我"一个解决困难的动作。** 老师问的是"怎么解决的"，现在的答案是精卫一个人给的。示例：*风把精卫嘴里的石子吹跑了，我伸手去接，差点从她背上滑下去，精卫用翅膀扶住了我。* 困难就变成两个人一起过的。
2. **立意落到"我"身上半句。** 示例：*我没有回答。我在想那只小小的鸟，想她在风雨里说的那句话——我不能让它夺走更多的生命。* 再接"若有所思……"，留白不破，立意有了落点。
3. **加一个时间标记，让"一天"闭合。** 示例：到西山后写一句*太阳斜斜地落在海面上，把浪染红了*；结尾妈妈的呼唤就是晚饭时间，题目的"一天"有头有尾。

转录与连缀成篇是习作单的记录，一个字不动；润色版也保持现状——这三处是课堂成篇的方向，现在塞进润色版就等于替她把成篇写了。

## 勘误与存疑

1. 「我吓的到处乱逃」的"到"与"处"之间有一处淡痕，似擦改残留，按"到处"读。
2. 「红色的脚」后的标点原迹为实心点，判为句号；亦可能为写得较小的逗号。若为逗号，外貌一节应读作一整句。
3. 栏格右边界外溢出的字（"更多的生命！""若有所／思……"）已按语序接回正文，位置不作额外标注。
4. 习作单页眉的校名、班级、姓名栏不进公开页；原图留在本地 `homeworks/我和精卫过一天/`，不进仓库。
