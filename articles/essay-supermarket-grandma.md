# 我的超市达人——奶奶

四年级上册语文的写人习作，题目自拟。孩子写奶奶逛超市，交回来是一整页红笔。这篇把**铅笔原稿**、**老师的修改**、**改完的样子**三样并排放，最后总结一下老师的批改到底在要求什么。

四份内容的关系：

| 部分 | 是什么 |
| --- | --- |
| 一、原文＋批注 | 孩子铅笔写的每个字，老师的红笔用颜色标出来 |
| 二、融合版 | 只把老师的批注落实，不加任何自己的润色 |
| 三、润色版 | 在融合版基础上，用四年级的口吻顺一遍 |
| 四、批改说明了什么 | 从红笔反推老师的评价标准，以及下次写作要注意什么 |

## 二、融合版

只把红笔的修改照搬进句子，一个字都没有额外加工。

<div class="essay-body">

我奶奶今年70岁了，她最大的爱好就是逛超市。

奶奶逛超市可勤快了，隔三差五就去山姆超市买一大堆东西回来。有一次我在家里写完了作业，却发现奶奶不见了踪影，于是我们全家人分头行动，爷爷找客厅，爸爸找洗手间……正当我们着急商量要不要出门寻找时，结果临近傍晚，奶奶搬着沉甸甸的两大袋物品，喘着气回来了，一脸不好意思地说："我去了山姆超市，今天有特价品，我去抢了很多，看你们忙，就没告诉你们。"

奶奶对商场熟悉得像自己家一样，哪个商品在哪个通道、哪个货架，她闭着眼睛都能说出来，每次她脚步轻快地推着购物车向"目标"前进，眯起眼仔细看价格和保质期，满意就往手推车里一放。有一次货架换了位置，她还是按老路线走，眉头轻轻皱起，左看看右看看，就是没找着，看着奶奶那幅迷茫的样子，逗得我哈哈大笑！

奶奶对自己精打细算，买东西都挑特价的商品，要是我喜欢，就不一样了。有一次我盯着货架上进口巧克力，不舍得买。奶奶一眼看穿我的心思，笑着二话不说拿起六大包放进手推车。我急忙拉住奶奶的衣袖："算了吧！奶奶，太贵了！"她摆了摆手，眼角弯成月牙，笑着回答："没关系，咱们孙女爱吃，奶奶花钱高兴。"

我的超市达人奶奶，对自己节俭，对我们从不计较。她购物车里装的不仅仅是货物，更是对我们满满的爱。

</div>

这一版读起来别扭的地方，都是**忠实照搬**造成的，不是抄错了：

- 「正当我们着急商量要不要出门寻找时，**结果**临近傍晚」——①号插入语和"结果"语义重复，"结果"该删，但老师没划它。
- 「笑着**二话不说**拿起六大包」——③号插入语接在"二话不说"前面，"笑着"和"二话不说"意思打架。
- 「盯着货架上进口巧克力」——老师把"了我最喜欢的"整段划掉，"货架上"后面就少了个"的"，读着断。

## 三、润色版（四年级口吻）

在融合版基础上只做顺句：把上面三处打架的地方顺掉，把"东西""很多"这类空词换掉，长句断短。**不加**新事例、**不补**心理描写、**不用**成语堆——那是大人写的，不是四年级写的。

<div class="essay-body">

我奶奶今年70岁了，她最大的爱好就是逛超市。

奶奶逛超市可勤快了，隔三差五就去山姆超市，每次都要拎回一大堆东西。有一次我在家写完作业，却发现奶奶不见了踪影。我们全家人分头行动，爷爷找客厅，爸爸找洗手间……正当我们着急商量要不要出门寻找时，临近傍晚，奶奶搬着沉甸甸的两大袋物品，喘着气回来了，一脸不好意思地说："我去了山姆超市，今天有特价品，我去抢了很多。看你们忙，就没告诉你们。"

奶奶对商场熟得像自己家一样，哪个商品在哪个通道、哪个货架，她闭着眼睛都能说出来。每次她脚步轻快地推着购物车向"目标"前进，眯起眼仔细看价格和保质期，满意了就往车里一放。有一回货架换了位置，她还是按老路线走，眉头轻轻皱起，左看看右看看，就是没找着。看着奶奶那副迷茫的样子，逗得我哈哈大笑！

奶奶对自己精打细算，买东西专挑特价的。可要是我喜欢，就不一样了。有一次我盯着货架上的进口巧克力，不舍得买。奶奶一眼看穿我的心思，笑着拿起六大包放进购物车。我急忙拉住她的衣袖："算了吧！奶奶，太贵了！"她摆了摆手，眼角弯成月牙："没关系，咱们孙女爱吃，奶奶花钱高兴。"

我的超市达人奶奶，对自己节俭，对我们从不计较。她购物车里装的不只是货物，更是对我们满满的爱。

</div>

改动清单（下表是改动较大的几处；另有"有一次→有一回""熟悉→熟""要是→可要是"这类小微调未逐条列出）：

| 原句 | 改成 | 为什么 |
| --- | --- | --- |
| 正当我们着急商量要不要出门寻找时，**结果**临近傍晚 | 正当我们着急商量要不要出门寻找时，临近傍晚 | ①号插入语已经表示"正在那时"，"结果"重复。老师补的"搬着沉甸甸的两大袋物品，喘着气回来了"原样留着 |
| **笑着**二话不说拿起六大包 | **笑着**拿起六大包放进购物车 | "笑着"和"二话不说"打架。删孩子自己的"二话不说"，留老师补的"笑着" |
| 盯着货架上进口巧克力 | 盯着货架上**的**进口巧克力 | 老师划掉"了我最喜欢的"之后，"货架上"直接接"进口巧克力"读着断，补一个"的" |
| 买一大堆东西回来 | 每次都要拎回一大堆东西 | "拎"比"买"有画面 |
| 有一次我在家里写完了作业 | 有一次我在家写完作业 | 删虚字 |
| 满意就往手推车里一放 | 满意了就往车里一放 | 前半句已经出现过"购物车"，不必再重复"手推" |
| 都挑特价的商品 | 专挑特价的 | 后半句"的商品"是废话 |
| 我急忙拉住奶奶的衣袖 | 我急忙拉住**她的**衣袖 | 上一句刚说过"奶奶"，这里换"她" |
| 看着奶奶那**幅**迷茫的样子 | 看着奶奶那**副**迷茫的样子 | 量词用错，老师没标，这里补上 |
| 不仅仅是货物 | 不只是货物 | 四年级说话不说"不仅仅" |

## 四、这些红笔，说明了老师的要求

把红笔按类型数一遍，共 36 处。分类有交叉（一处改动可能同时算两类），所以数字只用于看倾向，不是精确统计：

| 类型 | 处数 | 举例 |
| --- | --- | --- |
| 换词、升级用词 | 7 | 都飞快的→脚步轻快地、日期→保质期、拿起一个商品一看→眯起眼仔细看、省了再省→精打细算、可→要是、精打细算→节俭 |
| 错别字、含红笔重写的同字 | 7 | 号→好、勾→购（两处）、堆、搬、抢、算 |
| 不会写、用拼音顶 | 6 | qín、gé、bàng、bì、jiào、mímáng |
| 补写神态·动作（把概括换成画面） | 5 | 「沉甸甸的两大袋物品，喘着气回来了」、眉头轻轻皱起、一眼看穿我的心思，笑着、眼角弯成月牙、急忙 |
| "的／地／得"用错 | 5 | 不好意思**的**说→地、逗**的**我→得、熟悉**的**像→得、装**得**→的 |
| 删冗字赘词 | 3 | 隔三差五**地**、没找着**儿**、**那**就不一样 |
| 标点 | 2 | 通道**、**货架；不舍得买**。** |
| 补叙事逻辑 | 1 | ①正当我们着急商量要不要出门寻找时 |

一个值得注意的比例：**字词层面（错别字 7＋拼音 6＋的地得 5＝18）和写法层面（换词 7＋神态 5＋删冗 3＋标点 2＋逻辑 1＝18）正好对半**。老师在这篇上花的一半力气纠正"写对没有"，另一半才是在管"写得好不好"。

### 老师真正在意的三件事

**第一，别用概括代替画面。** 补写的五处全是同一件事：把"说了什么"换成"看得见的动作"。「拿起一个商品，一看价格」被换成「眯起眼仔细看价格」，「都飞快的推着车」被换成「脚步轻快地推着购物车」，「按老路线走」后面被塞进「眉头轻轻皱起」。老师要的是**能拍下来的那一秒**：眉头皱起来、眼角弯成月牙、两大袋压得喘气。这些都不是形容词，是镜头。

顺带一个反例值得注意：「买东西简直是省了再省」被换成「精打细算」，方向恰好相反——从具体收回到概括。老师要的不是"写得细"，而是**该细的地方细**：写奶奶的动作要具体，写奶奶的品性用一个词带过就行。

**第二，"的、地、得"是硬指标，一处都不放过。** 五处全改，无一遗漏。这是最机械、也最容易自己检查出来的错。

**第三，不许留拼音。** 六个拼音占位全被补上汉字，连"迷茫"两个字都是先写了拼音、再由老师改成汉字的。这说明老师把"不会写的字"当成作业的一部分，不是可以跳过的事。

### 夏末下次写作要注意的

1. **写完先数拼音。** 这次正文里留了六处拼音，就是六个字没掌握。这是零成本的自查。
2. **"的、地、得"单独过一遍。** 规则只有一句：名词前用"的"，动词前用"地"，动词后补状态用"得"。全篇搜这三个字，逐个问"后面是名词还是动词"。
3. **每段挑一个"概括句"，换成一个动作。** 「奶奶很高兴」→「奶奶眼角弯成月牙」。一篇作文里换出三处，就够用了。
4. **同一个词不许多次出场。** 这次"精打细算"第二段和结尾各用了一次，老师把结尾那个改成"节俭"。写完通读一遍，凡是重复的漂亮词，第二次就得换。
5. **插入语接上之后要重读。** ①号那句"正当我们……时"接进原文，就和后面的"结果"撞了。补完句子必须连着读一遍，光看插入的那句是看不出问题的。
6. **删字会带走语法。** 老师划掉"了我最喜欢的"之后，"货架上进口巧克力"就缺了个"的"。删完要检查剩下的词还接不接得上。
7. **长句砍成短句。** 原文一句"奶奶逛超市可勤快了……买一大堆东西回来"套了三层，改成两个短句后不需要任何新词就顺了。
8. **别用大人的连接词。** "不仅仅""简直是"这类词，老师都往轻了改。四年级的语感本身就是得分点，不用往成熟里靠。

## 勘误与存疑

**判读存疑已全部核对完毕。** 本稿最初有 5 处红笔压在铅笔字上、放大后仍判不准，已逐条对照原稿核定，其中 3 处我原先读错，现记录如下：

| # | 位置 | 我最初的判读 | 原稿实为 |
| --- | --- | --- | --- |
| 1 | 第 1 段「爱**号**」 | 号 | ✅ 判对，确实是错别字"号" |
| 2 | 第 3 段「每次她\_\_\_」 | 步快 | ❌ 实为「都飞快的」，老师整段换成「脚步轻快地」 |
| 3 | 第 3 段「价格和\_\_\_」 | 包质期 | ❌ 实为「日期」，老师把「日」改成「保质」，保留「期」 |
| 4 | 第 3 段「那幅\_\_\_的样子」 | 迷＋拼音máng | ⚠️ 迷和茫**都**是拼音，老师补了两个汉字 |
| 5 | 第 4 段「有一次我\_\_\_进口巧克力」 | 盯了我最喜欢 | ❌ 实为「看到了我最喜欢的」，老师改「看到→盯着」、划掉「了我最喜欢的」、增补「货架上」 |

第 5 条还连带纠正了融合版的一处抄写错误：既然被划掉的是"了我最喜欢**的**"，融合版就应作「盯着货架上进口巧克力」，我原先多留了一个"的"。

**本文另外两处需要说明的判断：**

- 标题按第 1 页实读为《我的超市达人——奶奶》，中间是破折号，"超市达人"没有引号。
- 第 4 段「拿起**六**大包」——孩子那个字写得像"6"，已确认为"六"。

**已修正的旧错：** 早期笔记曾把标题记成《我的"超市达人"》、把结尾记成"我爱我的'超市达人'奶奶！"，实读均不成立；"眯起眼仔细看""保质期"两处在第 1 页而非第 2 页。另有一版曾写"两个'了'叠在一起"，实际红笔是把「一大堆东西回来了」整段替换，成稿只有一个"回来了"，该说法已删除。本稿以两张原图的逐行扫描为准。
