# 暗黑破坏神 II：重制版｜暴风雪法师从零开荒速查

> 路线：充能弹 / Charged Bolt → 新星 / Nova → 约 30 级洗点为暴风雪 / Blizzard → 地狱安达利尔 → 地狱墨菲斯托。  
> 本文由此前的 PDF 版本整理为 Markdown，并补充了地狱佣兵生存建议。更新：2026-10-07。等级与刷图门槛是参考值，以实际任务进度、装备、抗性和存活率为准。

## 路线总览

| 阶段 | 目标 | 主要行动 |
| --- | --- | --- |
| 普通难度 | 推进剧情、取得任务技能点 | 做隐秘衣服，准备四孔剑；普通牛场在通关普通难度后开放 |
| 噩梦难度 | 升级暴风雪、补齐抗性 | 精神剑、知识头、洞察佣兵；按需求刷女伯爵 |
| 地狱第一幕 | 稳定击杀安达利尔 | 63% FCR 是常用传送起点；先顾抗性和生命，再逐渐加入 MF |
| 地狱第三幕 | 解锁并稳定刷墨菲斯托 | 憎恨囚牢注意娃娃；装备弱时可尝试卡河 |

**原则：** 力量满足当前装备需求，其他属性点优先体力；传送途中遇到冰免可绕过。魔法物品获取率（MF）没有必须达到的数字，稳定击杀和安全传送更重要。

### 第一次洗点前的属性

- **力量 / Strength：** 按现有衣服、腰带和武器要求增加。水晶剑 / Crystal Sword 要 43 力量；阔剑 / Broad Sword 要 48 力量。
- **敏捷 / Dexterity：** 不投；本路线不走格挡。
- **体力 / Vitality：** 其余投入体力。
- **精力 / Energy：** 新星阶段若缺蓝，可临时投入 10～15 点，第一次洗点时收回；同时多带法力药水。洞察的取得时间取决于符文和底材。

## 约 30 级：第一次阿卡拉洗点

用普通难度邪恶洞窟提供的免费重置，把新星法师转为纯暴风雪法师。下表假设角色已到 **30 级**，且取得普通难度邪恶洞窟、罗达门特、衣卒尔共 **4 枚任务技能点**。

| 系别 | 技能（中文 / English） | 硬点 |
| --- | --- | ---: |
| 冰 | 冰弹 / Ice Bolt | 1 |
| 冰 | 冰风暴 / Ice Blast | 6 |
| 冰 | 冰霜新星 / Frost Nova | 1 |
| 冰 | 冰尖柱 / Glacial Spike | 13 |
| 冰 | 暴风雪 / Blizzard | 7 |
| 冰 | 冰冷支配 / Cold Mastery | 1 |
| 冰 | 冰封甲 / Frozen Armor | 1 |
| 电 | 静态力场 / Static Field | 1 |
| 电 | 心灵传动 / Telekinesis | 1 |
| 电 | 传送 / Teleport | 1 |
| **合计** | **升级所得 29 + 普通任务 4** | **33** |

暴风雪从角色 24 级起开放，到 30 级最多投入 7 个硬点。若任务点不足，先减少冰尖柱和冰风暴的额外点数，各保留至少 1 点；保证暴风雪、冰冷支配、静态力场、传送及全部前置。

**属性重置后：** 力量按当前装备要求分配，常见约 43～50；敏捷和精力不追加，其余全给体力。此时无需为了未来的君主盾预先点到 156 力量。

## 31～70 级：暴风雪、冰冷支配和协同

| 来源或等级 | 技能（中文 / English） | 结果或停止条件 |
| --- | --- | --- |
| 31～43 级，共 13 点 | 暴风雪 / Blizzard | 从 7 补到 20 硬点 |
| 噩梦任务奖励，最多 4 点 | 冰冷支配 / Cold Mastery | 奖励到手时再分配 |
| 约 44～52 级，最多 9 点 | 冰冷支配 / Cold Mastery | 连装备加成约 17 级时先停 |
| 其后约 7 点 | 冰尖柱 / Glacial Spike | 从 13 补到 20 |
| 再往后 | 冰风暴 / Ice Blast | 补到 20；之后冰弹 / Ice Bolt |

噩梦邪恶洞窟、罗达门特和衣卒尔合计还有 **4 枚技能点**。如果这些奖励及时拿齐，且 44～52 级的九点都投冰冷支配，它将是 **14 硬点**；精神剑和知识头提供 +3 技能时，面板约为 **17 级**。若装备提供更多 +技能，提前停止投入冰冷支配，把点数改给协同技能即可。这个等级顺序是计划，不要求任务点恰好在指定等级取得。

**70 级点数校正：** 若 30 级洗点时冰风暴为 6 硬点，60～70 级的 11 枚升级点全部给它，70 级时是 **17 硬点**；再取得地狱邪恶洞窟、罗达门特奖励就是 **19 硬点**。补满 20 后把其余技能点投入冰弹。前版攻略曾把这里写得偏高，计算以此处为准。

最终核心为暴风雪 20、冰尖柱 20、冰风暴 20、冰弹尽量补到 20；冰冷支配随装备调整。静态力场、心灵传动、传送和冰封甲通常各 1 点。实战中用冰尖柱控制怪群，暴风雪打主要伤害，冰风暴补单体；Boss 可先用静态力场削血。

## 属性和剩余两次洗点

| 时点 | 力量 / Strength | 其他属性 |
| --- | --- | --- |
| 第一次洗点后，尚无君主盾 | 满足当前装备，常见约 43～50 | 敏捷、精力不追加；其余全部体力 |
| 已拿到君主盾 / Monarch | 穿齐其他装备后，力量达到 156 | 可用噩梦阿卡拉第二次洗点优化；也可直接用储存的属性点补足 |
| 后期更换配装或流派 | 重算装备提供的力量 | 地狱阿卡拉第三次洗点留作大改流派 |

例如其他装备和护身符合计提供 **+21 力量**，自身基础力量至少需要 **135** 才能穿君主盾。计算时要确认提供力量的装备能先穿上，避免摘下一件后连锁脱装。第二次洗点属于优化，不是装备君主盾的必要条件。

每个难度的邪恶洞窟各给一次免费重置，完成后可以留待日后使用。三次都用完后，地狱安达利尔或督瑞尔、墨菲斯托、迪亚波罗、巴尔分别可掉落四类精华；集齐后放入赫拉迪克方块合成 **赦免徽记 / Token of Absolution**，可再次重置技能和属性。

## 符文之语与底材

符文必须按下表顺序，放入**孔数和物品类型都正确的普通品质底材**；魔法、稀有、套装、暗金物品不能做这些符文之语。

| 装备（中文 / English） | 符文顺序 | 底材和作用 |
| --- | --- | --- |
| 隐秘 / Stealth | Tal + Eth | 2 孔衣服；25% FCR，前期跑图 |
| 古代人的契约 / Ancient's Pledge | Ral + Ort + Tal | 3 孔盾；前期补抗性 |
| 精神剑 / Spirit Sword | Tal + Thul + Ort + Amn | 4 孔剑；+2 技能，25～35% FCR |
| 知识 / Lore | Ort + Sol | 2 孔头盔；+1 技能 |
| 洞察 / Insight | Ral + Tir + Tal + Sol | 4 孔合适的佣兵武器；冥思光环回蓝 |
| 押韵 / Rhyme | Shael + Eth | 2 孔盾；抗性、不能被冻结、MF |
| 烟雾 / Smoke | Nef + Lum | 2 孔衣服；全抗 +50 |
| 精神盾 / Spirit Shield | Tal + Thul + Ort + Amn | 4 孔君主盾；156 力量，+2 技能 |

等级门槛大致为：隐秘 17、古代人的契约 21、精神 25、知识和洞察 27、押韵 29、烟雾 37、君主盾底材 54。等级达标不代表材料已经到手。

普通牛场掉落的**白色无孔水晶剑**交给拉苏克可打出 4 孔；别把任意地点掉的水晶剑都当成必出 4 孔。白色无孔君主盾最大 4 孔，交给拉苏克可打成 4 孔。无孔底材不是魔法物品，天然 4 孔也可以直接使用。

**FCR（快速施法）**的常用目标是 **63% → 105%**。精神剑和精神盾各随机提供 25～35%，隐秘提供 25%；按物品实际面板求和。例如双精神各 25%，合计 50%，还需至少 13% 才达到 63%。

## 地狱安达利尔到墨菲斯托

| 地点 | 做法 |
| --- | --- |
| 地狱安达利尔 / Andariel | 能稳定击杀后再重复刷；获得明显装备升级就继续推进 |
| 地狱第二、三幕 | 冰免可以绕过；在憎恨囚牢中不要停在怪堆，尤其小心娃娃死亡爆炸 |
| 地狱墨菲斯托 / Mephisto | 装备偏弱可尝试卡河；佣兵若总冲向 Boss 干扰站位，可以不带佣兵 |

约 **100 MF** 可以作为逐渐加入 MF 装备的起点，不是开刷门槛。后续可留意蛇魔法师之皮 / Skin of the Vipermagi、法师之拳 / Magefist、谐角之冠 / Harlequin Crest、眼球 / The Oculus、蜘蛛之网 / Arachnid Mesh。精神剑和精神盾足够支撑很长一段刷图期。

## 地狱佣兵容易倒：补充处理顺序

此处以第二幕、使用洞察的佣兵为例。

1. **先看等级和抗性。** 若佣兵明显低于角色等级，先带他在较容易的区域升级。地狱会降低佣兵抗性；缺抗性时，2 孔衣服做烟雾（Nef + Lum）提供即时全抗 +50。
2. **头盔补生命偷取。** 有塔拉夏的赫拉迪克纹章（俗称塔拉夏面具）可先给佣兵，提供 10% 生命偷取、全抗和生命。吸血依赖他的物理伤害；低伤害洞察底材应升级为更高伤害且佣兵能装备的四孔底材。地狱的生命偷取效果会受惩罚。
3. **战斗中主动救人。** PC 默认可用 `Shift + 药水快捷键` 把腰带药水给佣兵。红药回血需要时间，快死时用回复活力药剂；传送到安全位置把佣兵拉离怪堆。
4. **有 Lem 时考虑背信 / Treachery。** 三孔衣服，符文顺序 `Shael + Thul + Lem`；有攻速与受击触发 Fade。若佣兵现在一碰就倒，烟雾的即时抗性更直接。
5. **刷墨菲斯托卡河时可以暂时不复活佣兵。** 他冲到 Boss 身边可能破坏站位；憎恨囚牢的娃娃也不适合让佣兵贴身击杀。

优先检查：**佣兵等级、地狱抗性、头盔是否有生命偷取、洞察底材伤害**。这些通常比单纯增加盔甲防御数字更能解释为什么他站不住。
